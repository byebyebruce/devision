# 可选的读数模式（devision.reading；exp56 起，未发布）

本文件说明一个**可选、默认关闭**的推理模式，补充 `vision-decision-mvp.md`。它不改变默认推理、HTTP API、Jev 响应结构、发布包或线上模型。

## 做什么

`devision.reading.Reading` 绑定一个带 12 个局部视图（12 / 0.25 / T）的决策 checkpoint，以及一个读数包（`selector.pt`、`head.pt`、`reading.json`）。处理一次请求的步骤：

1. 用请求自带的图片，经 checkpoint 自己的局部视图路径编码：全图加 12 个视图。全部题都受支持时每个请求编码一次；混合请求（还有不受支持的题）编码两次，一次读取，一次在普通 decide 中。
2. 区域选择器（exp53）对每个内部读数问题预测一个框。
3. 字符头（exp51）读出框内的数字，严格解码，加千位分隔符（exp55）。
4. 写成事实表，接在文字 state 后面。
5. 受支持的题用普通 `decide(..., image=None)` 作答，即模型只看文字和表（与 exp55 验证过的接口相同）。

不训练，不使用金标、预存的框或候选匹配，不计算物理公式。

## 支持范围（有限，按问题文本匹配）

- **6 个读数问题**：样本 A / B 的粒子质量、平均速度；Pair 1 / 2 中磁铁的距离。
- **2 个比较问题**：哪个样本温度更高（粒子平均动能）；两组磁铁之间的磁力。
- **路由规则**：
  - 请求中只要有受支持的题，就读取该领域的全部数值（温度 4 个，磁铁 2 个）；读取集合与题号和选项顺序无关；
  - 只提交一道比较题时也会读取；
  - 受支持的题用"文字 + 表"作答；同一请求中的其他题照常走"带图的普通 decide"；
  - 没有图片或没有受支持的题时，完全等同于普通 decide。
- **不读取的信息**：样本 id、文件名、数据集字段、gold、候选答案、预生成框都不参与路由或读取。
- **磁铁表只有距离**：磁铁大小 / 极性没有读出，这类比较不能视为输入完整。
- **不是通用问题分解**：其他版式和其他问题没有覆盖。

## 身份

`reading.json` 用 sha256 绑定：
- selector.pt 和 head.pt；
- 决策 checkpoint 的 model.safetensors、config.json；
- tokenizer 目录（选择器用它的词嵌入）；
- 策略版本（templates-v1）和网格。

`Reading.load(decision_dir, bundle_dir)` 先逐项核对，再由它自己从同一目录加载 Decider，不接受调用方传入的模型；任何一项不符都拒绝。`Reading._attach` 不做这项核对，只供内部和 CPU 夹具使用，不是已验证的公共入口。float16 的边界（选择器的 patch 和词嵌入、字符头的区域特征）与 exp53 / exp51 相同。诊断信息只通过可选的 `diagnostics` 字典返回，不进入响应。
