背景和方案见 `docs/experiments/2026-10-08-r13-binding-plan.md`。本文汇总三路网上调研。标「未核实」的是调研时没有打开一手页面确认的内容；2025–2026 年的预印本只读了摘要或 HTML 摘录，具体数字以原文为准。

几乎没有小模型专门为绑定做设计。可以借鉴的教训：
1. **由问题控制的读出**：[Foveated Probes](https://arxiv.org/abs/2608.00726) 用冻结的 SigLIP2，绑定从 3.5%（全局池化）升到 93.5%（按问题生成 query 的注意力池化）；但 GQA 真实图成对颜色题只有 4.3% → 17.0%（oracle 33%）。
2. **训练时用框或点监督**（X-VLM、FIBER、MDETR，以及 [Point by Point](https://arxiv.org/html/2605.25427)：先指点再回答能消除绑定错误）。
3. **成对的反事实难负例**（ARO、NegCLIP，CLIP 关系 0.59 → 0.80）。但 [SugarCrepe](https://arxiv.org/abs/2306.14610) 指出 NegCLIP 的收益多来自文本伪迹。
4. **图表上的两处比较**：[FigureQA](https://arxiv.org/abs/1710.07300) 原论文 8×8 特征图 + Relation Network、130 万题才到 72.4%；CNN+LSTM 约 56%。[VisOnlyQA](https://arxiv.org/abs/2412.00947) 的作者也说，用它的训练集微调不总是有效。
5. **token 数和分辨率**收益小（[M3](https://arxiv.org/html/2405.17430)：GQA 在 36 / 144 / 576 个 token 下为 60.3 / 61.3 / 61.9）。是否解冻视觉塔证据互相矛盾（[Prismatic](https://arxiv.org/pdf/2402.07865) 说有害，[Cambrian-1](https://arxiv.org/abs/2406.16860) 说有益）。

**构造难负例的原则**：
- 干扰选项必须来自同一张图里真实存在的另一个物体（最好是最显眼的那个）；
- 每题记录"只看最显眼物体时会选哪个"；
- 成对的两张图放在同一批训练。

**图片污染**：
- NegCLIP 的 COCO 负例、ARO 的 COCO-Order 用了 val2014，不能用；
- VisMin 训练集和 PACO 用的是 COCO 2017 train，里面约 3.5 万张来自 val2014，要按 id 剔除。

## 三、训练方法

| 方法 | 证据 | Mac 训练成本 | CPU 延迟 | 结论 |
|---|---|---|---|---|
| 最小对照合成 + 真实图反事实 | 我们的镜像对；[SAT](https://arxiv.org/abs/2412.07755) CVBench +23%；[CounterCurate](https://arxiv.org/html/2402.13254)；反证：[只用合成迁移不到真实图](https://arxiv.org/html/2502.15678v2) | 低 | 0 | **必做**，必须混真实图 |
| 视觉 token 级的定位辅助损失（框 / 点 → 注意力 KL） | [KLAL](https://arxiv.org/abs/2511.12738)、Point by Point、[Molmo](https://arxiv.org/html/2409.17146v2) 先指点再计数、[注意力先验](https://arxiv.org/pdf/2205.12616) | 中 | 0（推理时不用） | 筛选 S1 |
| 按问题生成的池化 token | Foveated Probes、InstructBLIP | 中 | 估 +5–15 ms | 筛选 S2，改结构 |
| 改注意力窗口 / 视觉 token 位置 | 只有推断 | 低 | 估 < 10% | 已排除：目标在图上方或下方结果相同 |
| 加大 LoRA 秩 / 全量微调 ModernBERT | 我们以前 r=64、全量放开都无效 | — | 0 | 不做 |
| DINOv2 + SigLIP | Prismatic 定位类 +5–10%；[MMVP](https://arxiv.org/abs/2401.06209) | 中到高 | 估 +30–60 ms | 筛选判定"都不动真实照片"后再考虑 |
| 部分解冻 SigLIP | 证据矛盾 | 每步慢 30–50% | 0 | 同上 |
| 更多视觉 token | [MM1](https://huggingface.co/papers/2403.09611)、[Honeybee](https://arxiv.org/html/2312.06742v1)；我们的筛选 D 无收益 | 中 | 约 2 倍 | 不做 |
| 从大 VLM 蒸馏软标签 | [LLaVA-KD](https://arxiv.org/pdf/2410.16236)；[更强的老师不一定更好](https://arxiv.org/pdf/2511.17886) | 高 | 0 | 不做 |
| hard negative 对比 / ITM 头 | [TripletCLIP](https://arxiv.org/abs/2411.02545) SugarCrepe +9%；ALBEF 只 +0.4 | 低 | 0 | 并入数据项：干扰选项设成显眼物体的属性 |
| 测试时裁剪再问 | [ViCrop](https://arxiv.org/abs/2502.17422) | 0 | 约 2 倍 | 不做（概率要重新校准） |
| 检测器 / SAM 区域 token | [Slot-MLLM](https://arxiv.org/abs/2505.17726) | 高 | +50–300 ms | 不做 |

另：[Campbell et al. 2024](https://arxiv.org/abs/2411.00238) 把这类失败归为前馈式的绑定容量限制，与"加容量没用、加空间监督有用"的经验一致。
