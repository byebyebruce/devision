## 1. 直接影响 S1 / S2 解释的证据

| 编号 | 方案主张与位置 | 一手事实 | 判断及边界 |
|---|---|---|---|
| P01 | 计划第 40 行、调研第 20 行：3.5% → 93.5% 来自按问题生成 query | Foveated Probes 的 Synthetic Binding Tasks 是视觉单模态六分类，query 是跨图片共享的学习参数；GQA 才用冻结文本编码器产生问题向量后线性映射为 query。3.5% / 93.5% 是合成题**两张反事实图都正确**的成绩，不是单题准确率。见 [方法 Frozen-Encoder Readout Protocols、Tasks、Table 1](https://arxiv.org/html/2608.00726v1)。 | **需更正机制口径**。该数字支持自适应空间读出，不能作为“问题条件化带来 90 个点”的消融。GQA 表中的 SigLIP 17.0 / oracle 33.0、SigLIP2 25.4 / oracle 37.8 已核实，修订正确；均非本模型上限。原文主实验 SigLIP 是 So400m / patch14 / 384，亦非本项目 B16 / 256。 |
| P02 | 计划第 84 行、调研第 60 行：题干 / 选项位到 64 视觉 token 做 KL | KLAL 原文 §3 用**最后答案 token**查询视觉 token；每个头先在视觉子集归一化，再平均头，逐层计算 `KL(P || Q)` 后平均；目标由点或框中心线对应 patch 平滑并归一化，最终为 NTP + λKL，论文 λ=1。附录层 / 头消融表支持其设置下逐层、平均头。见 [KLAL §3、补充材料 §4](https://arxiv.org/html/2511.12738v2)。 | **重要，需补方案**。原文是全局因果 LLaVA / Qwen 的生成式训练。题干 / 选项、双向局部窗、RLCD、整框目标均为新迁移变量。执行者需先固定 query 位置、可见视觉 token 的监督层、归一化、GT 映射与平滑、λ及无目标框样本处理，再比较 S0 / S1。并非断言 S1 做不了；不能把原文 λ=1 或所有层直接视为本架构的已验证选择。 |
| P03 | 调研第 21、60 行：Point by Point 支持训练时定位辅助损失 | 该研究训练模型**串行输出坐标再回答**，并分析其内部搜索注意力；训练不直接监督内部 attention。§3 同时报告真实图计数仍困难；§4 明确专门任务上的证明不能自动推广到广泛任务。见 [Point by Point §3–4](https://arxiv.org/html/2605.25427)。 | **方法类型需分开**。它支持串行定位作为候选，不是“训练时 KL、推理零开销”的直接证据。S1 的直接方法来源应是 KLAL；S2 单次交叉注意力也不等价于串行点选。 |
| P04 | 调研第 15、61 行：InstructBLIP 支持问题条件读出 | InstructBLIP 将指令同时送入 Q-Former 和 LLM；移除 Q-Former 的指令输入在空间 / 时间推理集合下降更大。见 [§3 与 §4.4 消融](https://arxiv.org/html/2305.06500)。 | **方向成立**。支持 S2 的动机，未验证“4–8 token、单层、词嵌入 query、插在视觉后”的具体方案，也不能从其性能推出本机 +5–15ms。 |

S1 最小验收建议（由执行者实施）：先在有准确框的少量合成样本验证 GT 映射、非空视觉支持集、有限 KL、梯度确实传到预期参数；记录辅助项相对主损失的量级、每步时间和显存，再进行固定预算对照。否定存在题、两物体比较、计数多实例没有统一的“那个目标框”，需分别定义目标集合或明确跳过辅助项。对于有局部注意力的层，不能让 GT 在 mask 外有质量而期望模型学到不可达注意力。这些是由方法与架构差异推出的要求，不是原论文对 deVision 的实验结论。

| P05 | 计划第 46 行、调研第 72 行：“主流结论不靠加容量”；Campbell | [Campbell 等 §6 / §6.1](https://arxiv.org/html/2411.00238) 研究多物体干扰、组合表示和串行处理，主要模型的训练与结构不透明；没有隔离参数规模的受控实验。把视觉注意容量约束改写成“加参数没用”不成立。作为解释性假设保留，不作为排除更大主干 / 更高秩的证明。 |
| P06 | 调研第 23 行：VisOnlyQA 微调不总有效 | [VisOnlyQA §4.4、§4.5、Table 8](https://arxiv.org/html/2412.00947) 确实报告效果依赖任务；同时，同一视觉编码器配更大语言模型表现更好，且在部分设置有配对显著性。故“单靠数据不总够”得到支持，“模型容量不重要”不支持。几何感知也不能直接等同于本轮颜色绑定。 |
| P07 | 计划不增加 token；调研第 24 行 M3 数字 | [M3 Table 1 与 §4.4](https://arxiv.org/html/2405.17430) 的 36 / 144 / 576 对应 GQA 60.3 / 61.3 / 61.9，数字准确；属于专门进行多尺度训练的 LLaVA-1.5-M3。原文亦显示启发式删 token 比其方法下降更大。只能说明这种训练下总分较稳，不能外推当前绑定小物体任务或 64 → 256 的效果。 |
| P08 | MM1 / Honeybee 支持或排除更多 token | [MM1 作者摘要](https://arxiv.org/abs/2403.09611) 明确认为图像编码器、分辨率及 token 数影响显著；本文未读到完整 HTML 实验表，不能给统一量化结论。[Honeybee §3、附录局部性消融](https://arxiv.org/html/2312.06742v1) 强调灵活 token 数与保留局部结构，而非 token 越多越好或无用。现有证据支持任务依赖的取舍。 |
| P09 | Prismatic 与 Cambrian 对解冻结论相反 | [Prismatic §4.1 / Figure 5](https://arxiv.org/html/2402.07865) 在其数据与训练设置下解冻视觉塔退化，作者提出数据规模和目标差异等解释；[Cambrian-1 Figure 7、Table 15–16](https://arxiv.org/html/2406.16860) 在自身配方下解冻常有收益，部分任务仍下降。调研写“证据矛盾”可保留，宜明确为条件不同，不是二者互相证伪。 |
| P10 | DINOv2 + SigLIP 定位收益 5–10% | [Prismatic §4.2](https://arxiv.org/html/2402.07865) 有此范围的报告，指其定位及挑战任务；支持候选方向，非 deVision 的预期收益。+30–60ms 与解冻每步慢 30–50% 未提供本机依据，保留为预算假设而非事实。 |

本轮先试 S0 / S1 / S2、暂不做大架构变更可以是合理预算安排。修订后的 D 实验描述已经限定迁移预算且承认仍为 64 token，这一修订正确；不能再把 D 引作“更多 token 无收益”的直接实验。

## 5. 验收边界与建议处理顺序

1. **执行前需要补齐**：S1 的确定配方及合法 attention 支持集；S2 的 query 定义、初始化 / 短对齐预算和对照公平性交由总评审结合实现验收。所有论文收益仅作动机，实际去留由封存规则下的 dev 对照决定。
2. **文档更正，通常非阻断**：Foveated 固定 query 与问题条件 query 的区分；Point by Point 与 KL 辅助项分开；收窄“容量没用”“token 收益小”“合成不能迁移”等泛化断言；对未测成本写估计。保留本轮低成本优先的决策，不要求把所有候选路线再做一遍。
3. **未完成的验证**：未复现实验；未审核所有原论文代码；未逐个核对模型许可证和未采用路线的完整配置；MM1 只确认官方摘要而非全文消融；ALBEF +0.4 缺乏明确表口径；Laya 远端逐题基准复核依赖既有审计。数据集可获取规模、标签可靠性、历史训练污染与分割规则不在本子报告中证明通过。

以上限制不能替换本轮应有的执行前配置检查和执行后数据 / 模型验收，也不构成要求新增无关实验的理由。
