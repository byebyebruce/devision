# exp25 方案：读数练更久，同时用文字比较题补"比较两个数"（修订 1：评审 EXP25-I01 / I02 已改；未运行模型）

日期：2026-10-16。负责人："可以搞吧"（exp24 之后的推荐）。不算一轮，不产出可采用的模型。

## 背景与问题

exp24（`docs/experiments/2026-10-16-exp24-read-align-plan.md` 结果一节）：先做读字对齐，再跑 exp22 的配方，16 px 读数 fit 0.596、dev16 0.531，比 exp22 同题高 25 / 19 个点，曲线到 2,000 步仍在上升。按规则仍是"没拟合"。另外，比较两个数没有变好：两端都读对时比较只有 0.13–0.22，文字直接给出数值时比较 0.47。

这里问两件事：
1. 从 exp24 读字对齐后的 checkpoint 出发，读数题练两遍（约 5,000 步），16 px 读数能不能过线、能不能推广到未见族？
2. 加入"数值用文字给出"的比较题，能不能把比较两个数单独教会？读数和比较都会之后，图上的比较（要先读两个数再比较）能不能跟着过线？

## 设计

- **起点**：`runs/exp24-align/stage1`（exp24 阶段 A，r15 + 读字对齐，未经 exp24 阶段 B）。
- **设置**：与 exp22 / exp24 阶段 B 相同（视觉塔顶部 4 层 5e-6，学习率 2e-5 / 1e-5 / 5e-5，warmup 100，seed 1，micro batch 8）。只改三处：数据、2 遍、每 1,000 步监测一次（已 diff）。
- **数据**（`scripts/exp25/build.py`，`data/exp25/MANIFEST.json`）：
  - exp22 的 16 px 题 16,002 道（不变）：读数 10,668 道（readA / readB 各 5,334）+ 图上比较 5,334 道；
  - 文字比较题 4,000 道：新生成 2,000 个族（seed 25），两个数值视图，只问比较。图上不画数字（擦除图），两个数值和单位写在 `state_text` 里，与 exp21 的文字对照格式相同。排除规则（评审 EXP25-I02）：量名 + 三个候选值组合不与 exp21 的 dev 族重复；并且两个视图中任何一个所给出的"量名 + 单位 + A/B 两个数（不分顺序）"都不与 exp21 任何 dev 族的任一视图相同，重合就重抽。
  - 旧版数据（第 1 轮评审时观察的版本）原样保留在 `data/exp25.v1-observed-20261016/`：它与文字对照集有 16 道题（11 族）的比较信息相同，dev 两数对重合 25 个。新版重建后这两个交集都是 0（全量核对）；标签与文字里的数值一致，每族两个视图，4,000 题；exp22 的训练文件 sha256 不变（`e3b59313…`）。
  - 合计每遍 20,002 题、2,501 步，两遍 5,002 步。
- **监测**：第 0 / 1,000 / … / 5,000 步，另有第一遍结束时（第 2,501 步）一次，共 7 次（评审 EXP25-N02）；集合与 exp22 相同（fit / dev16 / dev / 擦除 / 文字对照，每次 8,400 题）。`scripts/exp25/chain.sh` 走 exp18 的链，第 5,000 步的记录写完后停止。为此 exp18 的链加了 `EXP18_STEP` 变量（默认 2000，原有行为不变，加了测试）。
- 文字对照集（exp21 的 `dev_syn_text`，100 个 dev 族、200 道比较题，数值给成文字）在训练中留出：它的量名 + 单位 + 两数对都不在文字比较训练题里。但它已用于 exp21 / 24 的诊断和本方案设计，是参与过决策的开发对照，不是独立盲测。

## 判定（运行前写下，结果出来后不改；`scripts/exp25/report.py`）

只读第 5,000 步，阈值沿用 exp21 / exp22（通过 = 点 ≥ 0.80 且下界 ≥ 0.75；未过 = 点 < 0.60 且上界 < 0.65；其余为阈值附近），按族重采样。

- 读数：exp22 的标签（fit / dev16 的 16 px 读数），不变。
- 文字比较：文字对照集的比较准确率。
- 图上比较：dev16 的比较准确率；两端都读对时的比较（附分母）只报告。

三态都按上面的规则判；**阈值附近不当作失败**，结局只写观察到的现象，不写模型内部执行了哪几步（评审 EXP25-I01）。

| 结果（按顺序判断） | 可以说 | 下一步候选（另写方案，不自动启动） |
|---|---|---|
| 擦除对照越线 | 作废 | 查数据 |
| dev16 读数通过，且 dev16 图上比较通过 | 在合成面板图上，这套组合设置下读数和比较都过线，并推广到未见族 | 写 r16 正式方案：并进正式配方，补 ScienceQA 的 temp / force，并保护旧能力 |
| 文字比较未过 | 这个设置下，数值给成文字的比较也没学会 | 先单独查比较（题型、候选、头） |
| 读数通过、文字比较通过，图上比较未过 | 单项都过线，但图上比较未过线，组合应用仍不足 | 让图上比较的训练题更多 |
| 文字比较通过、读数未过 | 比较过线，读数没过 | 加大读字对齐或读数训练 |
| 其他（至少一项在阈值附近） | 部分进展 / 不确定 | 交负责人 |

- 只报告：各步 fit / dev16 读数轨迹；dev 各字号的读数和比较；两个视图都读对 / 都比较对。
- 本实验不测旧能力，起点和训练都会改变模型；正式方案里必须量。
- 读数和比较同时改了，所以图上比较变好不能单独归因于哪一项；这是组合配方的检验。

## 已知限制

- 单种子、一组学习率；第 5,000 步只读一次。
- 文字比较题的格式与文字对照集相同。文字对照过线说明这种格式学会了，不等于任何写法的数值比较都会。
- 只用 Arial；只训 16 px，其他字号只报告。

## 预算（估计）

训练 5,002 步 × 约 1.32 秒 ≈ 1 小时 50 分钟；监测 7 次 × 8,400 题 × 0.064 秒 ≈ 63 分钟。合计约 2 小时 55 分钟，最多 3 小时 15 分钟。轮询粒度可能让训练多走到第 5,002 步并开始最后一次评测，报告只读第 5,000 步。
