# 决策侧比较监督方案（DECISION-CMP-PREP-01；只有文字方案和无模型数据统计，未改训练主干、未训练）

日期：2026-10-18。

## 问题定位

EXP55 中，金标数值表（G）下的读数题已达 0.992，但温度比较只有 117 / 300。P / G 约 95% 选 "sample A"（P 285 / 300，G 284 / 300），擦除表的 E 是 240 / 300。数值输入不是瓶颈，比较这一步本身没有学会，所以最小的可学性检验应放在决策侧。

## 数据统计（无模型，real_layout；train / tune / confirm 的族和 case 交集都是 0，与 MANIFEST 的 case_overlap 一致）

| | train | tune（只作开发评价） |
|---|---|---|
| 温度行 / 族 | 6,000 / 3,000（每族两视图） | 300 / 150 |
| 每行题数 | 5（4 读数 + 1 比较） | 5 |
| 比较题金标 A / B / neither | 2,244 / 3,000 / 756（37% / 50% / 13%） | 113 / 150 / 37 |
| 轴：same mass / same speed / both differ / equal | 2,282 / 1,518 / 1,444 / 756 | 125 / 72 / 66 / 37 |
| 金标选项位置 0 / 1 / 2 | 1,947 / 2,032 / 2,021 | 100 / 103 / 97 |

- **只选 A 的偏置**：train 中 A 只占 37%，选项位置均匀，所以"总选 A"在训练分布上得不到高分。模型的 A 偏置不是来自这批训练数据（更可能来自先前的混合训练）。训练需要报告 A / B / neither 的召回，而不只是总准确率。
- **反事实覆盖**：
  - 每个族的两个视图数值不同；
  - same mass / same speed 轴单独改变一个量；
  - equal 轴（756 题）是 "neither" 的唯一来源；
  - both differ 轴 A / B 各半。

## 方案（固定一套，不按 tune 选择）

- **起点和冻结**：
  - 从 EXP50-T 的决策权重开始；
  - 冻结视觉塔、projector / 条件模块、选择器、字符头，以及 ModernBERT 的词嵌入（选择器依赖它）；
  - 只训练决策 LoRA（r 16）和 Laya 选项评分头；
  - 目标只用金标 CE，不用 RLCD、interaction 或 region 辅助，也不重新联合学习读数。
- **输入与 exp55 的接口完全相同**：原 state_text 加金标数值表（千位格式，`devision.reading.serialise` / `fmt`），image = None，原题和原选项。
  - 训练 gold 本来就来自数据集；生成表时只用读数题的金标数值。数据准备阶段可以用公式核对 gold，推理时不用公式。
- **训练数据**（只来自 questions_train）：
  - 温度行全部 5 题：比较题 + 4 道读数题，读数题用来保留数值消费；
  - 磁铁行只用 2 道读数题，不用磁力比较：当前接口没有大小 / 极性，不能把只含距离的表当作完整输入来训练比较；
  - 固定抽样 2,000 个温度族（每族两视图，即 4,000 行，含 4,000 道比较题）加 1,000 个磁铁族的读数题；按族成批，候选每个 epoch 换序。
- **预算候选**：
  - 1,000 次更新，micro batch 8，约 8,000 题次；文字前向和反传估计约 0.4 秒 / 步，约 7 分钟；
  - 筛查：tune 上 G / P 两个条件的 2,400 次文字请求约 7 分钟；exist / science 保护集约 5 分钟；加载和报告约 3 分钟；
  - 合计约 25–30 分钟，硬上限 45 分钟。
  - 学习率：LoRA 5e-5、评分头 1e-5、预热 100（沿用已有配方，没有扫描）。
  - 回放：首轮不加带图回放，保持单变量。代价是 LoRA 也作用于图像题，所以必须测保护集；保护下降超过预写线时，下一轮再加回放。这一取舍在运行前写明。
- **固定末步**，不按 tune 延长或择优；冻结起点作同题基线。

## 预写判据（草案，交评论家定）

- **文字金标（G，tune）温度比较**：
  - 总体 ≥ 0.80（基线 117 / 300 = 0.39）；
  - A / B / neither 的召回各 ≥ 0.60；
  - equal 轴 ≥ 0.50；
  - 相对冻结起点的 case 簇区间下界 > 0。
- **自动事实表（P，tune）温度比较**：相对起点的收益区间下界 > 0。
- **读数题不退化**：G all ≥ 0.98，P all 不低于 EXP55 的 0.886 − 0.02。
- **保护**：exist / science 相对 EXP50-T 不低于预写容差（例如 −0.02）；完整的 v0.3 迁移和七保护仍是发布前的独立要求。
- **限度**：文字金标成功不等于自动图像成功；磁铁比较不在本方案范围内。
