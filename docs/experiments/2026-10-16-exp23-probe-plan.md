# exp23 方案：视觉特征里有没有数字——冻结特征上的数字探针（代码与测试已写，待评审，未运行模型）

日期：2026-10-16。负责人："可以"（exp22 之后的推荐）。不训练模型、不改任何权重；只在冻结 checkpoint 的特征上训练小探针。不算一轮。

## 要回答的问题

exp21、exp22 里 r15 学不会从图里选出印刷数字（exp22 只训 16 px 读数题，nll 全程停在 ln 3 附近，连训练题都没拟合）。但那两次只改了训练数据，"表示里有没有数字"和"决策训练用不上"分不开。

这里直接问：**一个两位数印在白图上，它的十位和个位能不能从下面三层特征里解出来？在哪一层丢的？**
- `siglip`：视觉塔最后一层的 256 个 patch 特征；
- `projector`：2×2 合并 + MLP 后送进 ModernBERT 的 64 个视觉 token；
- `encoder`：ModernBERT 最后一层在这 64 个视觉位置上的状态（输入 "[CLS] <视觉> [SEP]"，不带问题）。

另报 v12（原始冻结的 SigLIP2）的 `siglip` 层，看 r15 解冻顶部 4 层有没有影响（只报告）。

## 设计（`scripts/exp23/probe.py`）

- **图**：256×256 白底，一个两位数（10–99），位置随机，黑色 Arial；数字墨迹高 6 / 8 / 16 / 48 像素（字号由像素实测选出，沿用 exp21 的 `font_for`；48 px 是正对照）。每个字号训练 3,000 张（seed 1）、测试 1,000 张（seed 2）。
- **标签**：十位（1–9）和个位（0–9），机会约 0.10。
- **探针**（两种，都在 CPU 上训，特征按 float16 缓存，checkpoint 不变）：
  - `pooled`：token 的 [均值; 最大值] → LayerNorm → 线性分类；
  - `attention`：4 个可学的查询对 token 做注意力池化 → 线性分类（能挑出数字所在的位置）。
  - AdamW，lr 3e-3，60 遍，seed 0。
- **一层的数字准确率** = 两种探针里较好的那个，十位、个位准确率的平均（运行前定下）；95% 区间按测试图重采样。

## 判定（运行前写下，结果出来后不改）

阈值：**带有** ≥ 0.60，**没有** ≤ 0.20（机会 0.10）。以 16 px 为准；6、8 px 只报告。

| 条件（16 px） | 标签 | 下一步候选（另写方案，不自动启动） |
|---|---|---|
| siglip 在 48 px < 0.90 | 探针无效 | 先修探针 |
| siglip ≤ 0.20 | 视觉塔：SigLIP 本身不带 16 px 的数字 | 换更高分辨率 / 擅长文字的编码器 |
| siglip ≥ 0.60，projector < 0.60 且比 siglip 低 ≥ 0.20 | 投影层丢了 | 专门学读字的对齐阶段（训投影层） |
| siglip、projector ≥ 0.60，encoder < 0.60 且比 projector 低 ≥ 0.20 | 文本编码器丢了 | 解冻 / 加大文本侧学习率 |
| 三层都 ≥ 0.60 | 读出：特征里都有，决策训练没用上 | 改训练方式（辅助损失、更高学习率、读字式对齐） |
| 其他 | 不确定 | 交负责人 |

能说 / 不能说：
- "带有"只说明在这种干净的白底单数字图上，冻结特征里线性 / 注意力探针能解出来；不等于在 ScienceQA 的复杂图里也能，也不等于模型会用。
- "没有"只说明这两种小探针解不出来，不能证明信息完全不存在（更强的解码器也许可以）。
- 不碰 ScienceQA 数据，不评任何集合。

## 实施（已写好，未运行模型）

- `scripts/exp23/probe.py`：生成图 → 三层特征（`model.image_features` 与 `model.encode`，`torch.no_grad`）→ 两种探针 → `runs/exp23-probe/report.json` 和终端表。
- `scripts/exp23/test_probe.py`（15 项，无真实模型）：
  - 图里的数字墨迹高度符合字号（误差 ≤ max(1, 5%)），训练图和测试图不同；
  - 两种探针都能学会"墨迹 token 位置随机、带数字"的玩具信号（> 0.9），学不会"有墨迹无数字"的噪声（< 0.25）；
  - 判定的每个出口和边界（含 projector 低于 0.60 但比 siglip 低不到 0.20 → 不确定）；
  - tiny 模型端到端跑通四层（含 base）。
- `scripts/data/exp21_reading.py` 的 `font_for` 搜索上限从 60 号放宽到 90 号，以便画 48 px；exp21 已用的四个字号（8 / 11 / 15 / 22 号）不变，exp21 测试 8 项仍通过。
- pyright 0 错误。

## 预算（估计）

16,000 张图，每层一次前向（视觉塔共 4 次），MPS 上约 10–15 分钟；32 次探针训练在 CPU 上约 20–30 分钟。合计约 40 分钟，最多 1 小时。

命令：`uv run python scripts/exp23/probe.py --checkpoint runs/r15-vision/stage2 --base runs/v12-ext/stage2 --out runs/exp23-probe`
