# exp49 方案：真实版式的区域数值读出（冻结 EXP48-X；CPU 准备完成，未运行，等评论家的模型许可）

日期：2026-10-18。依据：评论家 EXP49-PREP-01..04（EXP48 终点之后）。

## 问题

在真实版式中，已知要读哪个区域时，能不能从当前模型的视觉表示里读出完整数值？目的是把"局部数值可读"和"问题 / 候选如何使用视觉内容"分开。

- 不再叠加 CE、MLM、region KL、interaction 权重，也不重复 576 步。
- 与 EXP23 不同：用真实版式、多对象、多位数和小数，读目标区域的完整字符串。
- 与 EXP44 不同：直接从区域视觉特征读字符，绕开问题、候选、ModernBERT 和冻结的 MLM 词表头。
- 与 EXP45 不同：检验内容能否读出，不只看注意力落在哪里。

## 固定对象与数据

- **模型**：EXP48-X 的最终冻结模型（`a8b92cb9…` / `c017a469…`）。全模型 eval / 冻结，只训练独立的小读出头；原 checkpoint 不改，读出头不作发布候选。
- **题单**（`scripts/exp49/build.py` → `data/exp49/questions.jsonl`，`80943a63…`）：
  - 训练读出头用 exp42 的 fit_O + fit_L，各 576 题；每题是一个"图片 × 对象 × 字段"，已核唯一，不把四次重复当新数据。
  - 读出用 fit_O / fit_L 和 rl_tune / rl_tune_L 的全部读数题（各 1,800）。
  - 共 4,752 题、1,760 张图、440 个族。
  - tune 不训练、不选超参、不选最佳步；它是反复使用过的诊断集，不是新的冻结确认集。
- **区域**：被问对象被问字段的框（EXP45 readout sidecar，已按实际画出的值核过）。按实际 letterbox 和 16 × 16（SigLIP patch）/ 8 × 8（projector token）网格，取有任何覆盖的格子；不按 gold 长度缩框。
  - 每题的格子数：16 × 16 网格上 4–24 个（均值 12.7），8 × 8 网格上 2–8 个（均值 5.2）。
- **目标**：gold 数字去掉千位逗号（"1,360 m/s" → "1360"），共 12 类（0–9、"."、EOS），5 个槽（规范化后最长 4 个字符，加 EOS）。
- **孪生供体**：同族、同对象、同字段的另一视图；数值改变的孪生：fit 各 576、tune 各 828。没有缺失的孪生。
- **连续框几何**（评论家 EXP49-R1-01 裁定）：只用格子集合和整数相对格坐标时，projector 8 × 8 网格上 fit_O 有 8 题、rl_tune 有 232 题与同图另一题的输入完全相同（如 rl01744 v0 sample A 的质量行与速度行），这是把框压成格子造成的信息损失，不是投影层本身的上限。
  - 两层统一加入由原框算出的连续几何：每个 token 的格中心相对框的位置 ((cx − bx) / bw, (cy − by) / bh) 和格大小相对框的比例 (cell / bw, cell / bh)，与图像 letterbox 坐标一致。这属于已允许的固定几何，不是字段或对象名。
  - 无模型复算（与 head 输入同精度）：加入几何后，两层的同图异目标碰撞都为 0；只看格子时 projector 为 240（fit_O 8 + tune 232），SigLIP 为 0。数值改变的孪生共 2,808 对，两层上两视图的 token 集合和几何全部相同，所以供体检验不需要删题。
  - 这 240 题作为运行前定义的难度切片，单独报告整串分数；主条件仍用全部题。几何可区分不等于特征里真有可读的两个数字。

## 特征（`scripts/exp49/extract.py`）

- EXP48-X 自己的 256 letterbox 预处理，不裁图、不放大、不重画；每张图一次前向。
  - SigLIP 末层的 256 个 patch（`model.vision_patches`）；
  - projector 后的 64 个视觉 token（`model.projector`），即进入 QuestionConditioning 和 ModernBERT 之前。
- 只缓存每题区域内的 token（float16）、它们相对区域左上格的 (行, 列) 和连续几何（4 维，float32）。
  - 按图片分批（16 张）前向，不保留计算图；区域数组（约 250 MB）留在内存中，最后一次写盘。
- **缓存大小**：SigLIP 4,752 × 24 × 768 × 2 B ≈ 175 MB；projector 4,752 × 8 × 1,024 × 2 B ≈ 78 MB。
- features.json 绑定：模型 / config sha、题单 sha、1,760 张图逐张 sha（汇总为一个 hash）、预处理、形状、features.npz 的 sha。probe 在训练前核对题单和特征文件的 sha，不一致就拒绝。

## 读出头与训练（`scripts/exp49/probe.py`；运行前写定）

- **结构**（两层相同，只有输入投影的维数不同）：
  - 区域 token 经线性投影到宽 256，加上可学的"区域内行 / 列"位置嵌入和连续几何的线性投影；
  - 5 个可学的字符查询，对区域 token 做一次注意力（4 个头）；
  - LayerNorm-MLP 给每个槽 12 类的输出。
  - 输入只有冻结的视觉 token 和它们在区域内的位置；没有问题、候选、答案集合、id、族、对象名或字段名。框只用来选 token，这是 oracle 特权，报告中写明。
- **损失**：每个样本对自己的有效槽（字符和 EOS）取 CE 均值，再在批内取均值；EOS 之后的槽不计。
- **训练**：fit_O + fit_L 共 1,152 题；seed 0；AdamW，lr 1e-3，weight decay 0.01；batch 64，按带种子的排列逐轮取；正好 1,000 次更新，取最后一步。两层各训一个头，用同样的种子和步数。
- **解码**：取到第一个 EOS 为止；没有 EOS、空串或不是严格数字（`^[0-9]+(\.[0-9]+)?$`）都记为无效；不按候选做最近匹配。

## 读出与预写条件

- **逐集**（fit_O、fit_L、tune_O = rl_tune、tune_L = rl_tune_L），字段等权：
  - 整串精确（逐字段的分子和分母）和宏平均；
  - 字符准确率（有效槽，含 EOS）；
  - 异值两对象全对；
  - 值改变孪生两视图全对；
  - 同答；
  - **供体检验**：用本题标签配上数值改变的孪生的区域特征，报告"真 − 供体"的整串差（case 连接簇，2,000 次，seed 0）和供体预测跟随孪生新值的比例。依图阳性仍可能含全图上下文，不称为已证明 OCR。
- **条件**（每层、原图 / L 分开；这是探针的投资条件，不是发布门槛）：
  - 有效性：fit_L 整串宏平均 ≥ 0.90、每字段 ≥ 0.75。不过时，阴性结果不能用来说"表示不可读"，只记为"这类读出没学好"。
  - 投资：tune 整串宏平均 ≥ 0.80、每字段 ≥ 0.60、两对象 ≥ 0.50、孪生 ≥ 0.50、真 − 供体 ≥ +0.20 且下界 > 0。
- **逐题明细**（评论家 EXP49-R1-02）：每层把全部 4,752 题的 key、真实和供体的槽位预测、解析结果、供体 key、目标写进 `details_<层>.jsonl`（首行记录特征、题单和模型身份），在重抽之前写盘；头权重另存为 `head_<层>.pt`，报告记录两者的 sha。`probe.py --recompute` 不加载模型，从明细重算读出、条件和分支；明细缺题、重复或供体不符时拒绝。正式运行结束时会核对重算结果与内存结果一致（recompute_matches）。
- **分支**（按评论家原文写入 `branch()`，按层区分"正证据 / 有效但未达条件 / 读出没学好"；评论家 EXP49-R1-03：任何把低分归到某个模块或分辨率上的分支，都要求该层的读出头有效，读出没学好的层只记为未定位；都不自动启动下一步训练）：
  - 两层原图都可读 → 优先改"问题选择目标内容并供给选项决策"的学习路径；
  - SigLIP 可读、projector 不可读 → 优先验证局部数值内容监督能否教会投影 / 共享视觉路径；
  - 只有 L 可读 → 考虑真实输入上固定的多视图 / 局部细节编码（框只能用于诊断或训练监督）；
  - 两个头 fit_L 有效性都不过 → 不能定位瓶颈，不外推为必须换大模型；
  - 其余 → 混合，照实报告。

## CPU 验证（`scripts/exp49/test_exp49.py`；第 1 轮补正后 11 项）

1. 目标和解析："1,360 m/s" → "1360"，"1," 被拒；需要 EOS；"."、空串、"1." 无效；超出槽数拒绝。
2. 损失按样本归一，EOS 之后的槽没有梯度。
3. 合成区域 token 携带数字时，读出头在留出样本上整串正确率 > 0.9；把标签打乱（图文不对应）后 < 0.05，说明它读不到 id 一类的东西。
4. 区域格子和相对位置符合框（16 × 16、8 × 8 各一例）。
5. 在 tiny 模型上跑提取：只保留区域 token，数值等于模型自己的 vision_patches；题单在提取之后被改动时，probe 拒绝。
6. 用构造的预测核对读出：整串、两对象、孪生、同答、真 − 供体、供体跟随率都按定义计算。
7. 格子完全相同时标入难度切片（8 × 8 和 16 × 16 各一例）。
8. 同样的格子、不同的框（rl01744 v0 sample A 的质量行与速度行）得到不同的连续几何。
9. 真实题单上（无模型）：加入几何后两层碰撞为 0，只看格子时 projector 为 240；2,808 对改变值孪生两层的输入几何都相同。
10. 明细写出后可无模型重算，结果与直接计算一致；缺题、重复、供体不符都拒绝。
11. 分支：SigLIP 正证据而 projector 读出没学好时，不归因于 projector；L 有正证据但原图的负面来自无效头时，不判为"只有 L 可读"；正常分支不受影响。
