## 冻结与配方（与 EXP61 相同的部分）

- **起点**：新选择器从 EXP53 的端点 8f10f1fd 出发，不从 EXP61 的 c98becfc 继续。
- **冻结**：EXP50-T 视觉（EXP57 端点 962503fb）、EXP51-T 字符头、EXP57 决策、生产读取规则。
- **配方**：架构、L1 + GIoU、AdamW 1e-3 / wd 0.01、100 步预热后 cosine、seed 0、2,000 步、取末步，都与 EXP53 / EXP61 相同；CPU 上训练。

## 数据（`scripts/exp62/build.py` → `data/exp62/`，只在 CPU 上生成，没有加载模型）

- **父图**：EXP61 train_V 的 200 个族（100 温度 + 100 磁力）共 400 张原图，就是生成器自己的文件 `data/real_layout/images/<family>_<view>.png`，不重新渲染，也不引入新字体或偏移。
  - 逐张核对：EXP61 的裁剪图正好是父图的第 [t, t + h) 行（t 由 exp61 的 crop_params 决定），像素逐位相同。400 / 400 张通过。
- **父图的框**：exp45 的 `original_box`（温度是半幅行带，磁力是宽标签带），裁到父图画布内；值必须在框内，另一对象的值不能碰到框。
  - 逐题核对：父图框平移 −t、裁到裁剪画布后，等于 EXP61 记录的裁剪框（误差 ≤ 1e-6）。1,200 / 1,200 通过。
- **配对**：每道父图题与其裁剪题的字段、对象、目标值、族、视图、文字一一对应（`pair` = 裁剪题 key）。
- **隔离**：与 tune_V（开发切片）的族交集 0、case 交集 0；与 exp49 全部族的交集 0。EXP61 的变体数据和开发题单不重建、不改值（构建时绑定 EXP61 questions c37e35eb 和 MANIFEST 02195a21）。
- **记录**：回放 1,152（fit_O + fit_L）+ train_V 1,200 + train_P 1,200 = **3,552**。
- **身份**：parents.jsonl 7cf76afd…，plan.jsonl 1abbf86a…，父图摘要 e733df2b…；MANIFEST 记录这三者、计数和隔离结果。

## 批计划（`data/exp62/plan.jsonl`，现在固定）

- **每次更新**：24 对「父图 + 裁剪图」（48 行，同一对相邻、不拆开）+ 16 行旧回放 = 64 行。
- **取样**：对子池（1,200）和回放池（1,152）各用一个 seed 固定的 torch.Generator（0 和 1）做排列，不够时补一轮新的排列。
- **计数**（已核）：
  - 2,000 次更新，128,000 次曝光：父图 48,000、裁剪 48,000、回放 32,000；
  - 每对正好 40 次，回放每行 27–28 次；拆开的对子 0；所有行都见过；
  - 按字段：质量 42,673、速度 42,667、距离 42,660；涉及 340 个族。
- **不按 dev 的失误重采样**。
