# exp121：exp120 + 手机 GUI 改写题再扩量（预写，2026-10-28 04:05，exp120 训练中）

**背景**：exp119（[文档](2026-10-28-exp119-v4-gui-phone-science.md)）判据 1–3 全过：12k AITW-shopping 改写题让未见网站的 `test_gui_shop_state` 对 exp118 +10.21 [+6.72, +13.70]（真图 59.8 vs 配错图 31.1），对 v0.4 15 个旧集合无一显著退步。训练池还有 AITW-general 约 29k、AITW-shopping 约 186k 未用。负责人 10-27 方向：优先扩量真实手机 / 网页操作数据。

**改动**（`scripts/data/v05/exp121_mix.py`，seed 121，`data/v05/exp121/MANIFEST.json`），以 exp120 训练文件为底（不改动）：
- + AITW-general 改写题 10,000（2,964 个未用 episode，整段取）；
- + AITW-shopping 改写题 14,000（1,737 个未用 episode）；
- GUI 合计 48k（general 16k / shopping 26k / Mind2Web 原题型 6k），占 33%（exp119 为 23%）；共 144,889 题（约 18.1k 步）。init、学习率、视觉解冻、CE、1 epoch、评测集同 exp120。

**对照**：exp120（直接底座，逐题配对）、exp119、v0.4；所有集合配错图 / 倒序对照。

**判据**（`devision-compare` 按图 95%）：
1. **扩量有效**：`test_gui_shop_state` 或 `test_gui_state` 的 AITW 部分相对 exp120 下界 > 0；两者真图 − 配错图仍 ≥ 10pp。
2. **网页不退**：`test_gui` 的 Mind2Web 部分相对 exp120 不低于 −3pp（点估计）。
3. **旧能力**：ScienceQA / dev_sqa、CV-Bench、test_ego / EgoThink 与其余 bench 相对 exp120 和 v0.4 均无显著退步。
- 1–3 都过 → GUI 按此比例进入 `r22-*` 配方；1 不过 → GUI 停在 exp119/120 的量；3 不过 → GUI 占比回到 23%。
- 若 exp120 自身判据不过，本实验对 exp120 的差仍可解释为 GUI 扩量效果，但 r22 配方去掉 exp120 中不过的那部分。

**预算**：训练约 45 分钟 + 评测约 50 分钟。`scripts/v05/chain_exp121.sh 580332 584833` 04:06 挂在 exp120 之后（日志 `runs/v05-chain/chain_exp121.log`、`runs/exp121-v4-gui-scale.out`），预计 06:50 前后评完。不拟合发布温度。
