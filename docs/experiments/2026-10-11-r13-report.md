# 第 13 轮（绑定）完整报告

日期：2026-10-11。范围：从 demo 发现问题（10-08）到第 13 轮正式训练验收（10-11）。详细数字的出处：方案 `docs/experiments/2026-10-08-r13-binding-plan.md`，实验记录 `docs/experiments/2026-09-30-rlcd-plateau.md` 末尾各节，训练日志 `docs/training-log.md` 的 r13-binding 一节，评审 `critic/critic.md`（本地）。代码在分支 `r13-binding`，产物在 `runs/`。

## 一、结论

1. **这一轮要解决的问题解决了**：模型从"答最显眼物体的属性"变成"按题目点名的物体作答"。封存的真实照片绑定测试 +7.6 个点，合成绑定测试"同图两类都对"从 0.14 到 0.63，What'sUp +30.5，demo 那张"三个红圆、两个绿方块"图答对了。
2. **但带来了明显副作用**：模型偏向答"否"，POPE 掉了 6.5 个点（三档首次全部低于 laya-vision），两项概率质量警戒触发，几个旧集合没能证明守住保护线。
3. **按训练前写下的采用规则，默认保留 v12**，是否采用由负责人决定。
4. **建议**：修正训练数据里是非题的"是 / 否"比例（当前"是"只占 41.7%），同一配方再训一轮（r13b），争取保住绑定收益、拉回 POPE。

## 二、问题与诊断

- **现象**（10-08）：三个红圆 + 两个绿方块，问"What color are the squares?"，v12 答 red（0.95）；把圆涂蓝就答 blue。v11 也一样。
- **程序化诊断**（`scripts/diag/binding_probe.py`）：v12 只有一种形状时颜色答对 0.987；两种形状时 0.71；"有没有绿色的圆"（绿的是方块）只有 0.05 答对。
- **信息在不在**：在送进 ModernBERT 的 64 个视觉 token 上训一个小探针，"某类物体的颜色"读出 1.00。合成图上信息在视觉 token 里，是后面没学会按名词取用。
- **对标调研**（`docs/research/binding-2026-10-08.md`）：小 VLM 普遍在分辨率和 token 数上下功夫；和绑定直接相关的是"按问题读出"、框 / 点监督、成对反事实数据。

## 五、副作用的原因

- **POPE**：模型偏向答"否"。adversarial 档答"是"比例 0.54 → 0.35、召回 0.83 → 0.62、精确率 0.77 → 0.88。
- **数据**：本轮训练的是非题"是"只占 41.7%（v12 50.1%）。合成题 34%（每个物体问"本色 / 另一类颜色 / 改后颜色"三句，多数为假）；回放为"不存在"保底 1 万道时，抽进的 Objects365 样本里"是"只有 15%。exp13-long 的混合也只有 43.5%，但它没评 POPE，无法对照。
- **温度**：是非题温度拟合到上限 5.0，与概率警戒、ECE 变差可能同源。
- 以上是候选解释，没有做"只改比例"的对照。
- **ScienceQA 必须看图的示意图题**又低了 6 个点（0.455 → 0.393）；本轮数据不含示意图，"同属性比较"在真实照片上也仍未证明高于机会，这一短板没有触及。

## 六、成本

- Mac M4（MPS）：筛选 3 × 约 3 小时、困难诊断约 1 小时、exp13-long 两次（第一次作废）约 15 小时、第 13 轮训练 10.7 小时 + 评测约 5 小时。
- CPU 推理延迟：S2 模块使单题基本不变、同图多题每题约 +6 ms（机器有负载时测）。
- 若换 RTX 4090 / 5090，同一轮训练估计 20–45 分钟（估算）。

## 七、下一步

1. **r13b（推荐）**：同一配方，只把是非题调回 50 / 50（合成题补"是"、回放"不存在"保底按题而不是按样本抽），重跑约 15 小时；验收规则不变。目标：保住绑定收益，POPE 回到 v12 水平，警戒不触发。
2. **作为取舍采用 r13**：接受 POPE −6.5、两项概率警戒和几个未证明守住的集合。
3. **示意图 / 比较两处**（ScienceQA 主体差距）需要单独立项，本轮的绑定数据不会自动带上去。
