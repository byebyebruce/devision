## 五、分支判定（看结果前写死）

**口径**：位置选择、相对位置选择、相对位置是非三个子任务分开算。比较量是差值 `Δ = 新模型同时对率 − v8 同时对率`，按原图做模型间配对重采样（2,000 次），给 95% 差值区间。`scripts/pair_stats.py` 现在只算单个模型的区间，执行 0a 前加上两模型配对差值。25% 只作"两次独立随机猜测"的参考，不作判据。

**每个子任务的结论**（最低实用收益：位置 +10 个点，相对位置两项各 +5 个点）：
- **有效**：Δ 的区间下界 > 0，且点估计 ≥ 最低实用收益；
- **本预算未见足够收益**：Δ 的区间上界 < 最低实用收益；
- **不确定**：其余情况。

**用到哪里**：
- 位置选择看 0a；相对位置两项看 0b 在 `dev_lr_pairs` 上的结果。0b 用的是监测集，相对位置在 dev 上题少（92 / 66 对），所以 0b 的"有效"在 v9 的留出评测里还要再验一次，结论以 v9 为准。
- 三项都是"本预算未见足够收益"：不做左右的 v9，第 9 轮改走其他数据候选（TallyQA 复杂计数、POPE 方向），另写方案。
- 只要有一项是"有效"或"不确定"：进入 S-mix。位置失败不否定相对位置，反之亦然。
- **S-mix 的继续 / 停止门槛**（修订 2，评审 R9-V9-03A）：全部在同一份锁定的 `data/v6/dev_lr_pairs.jsonl` 上、按子任务算，基线都是 v8 在该集合上的逐题结果（`runs/r9/v8_dev/`）：
  - `Δmix = both(S-mix) − both(v8)`，`Δpure = both(R 或 R-rel) − both(v8)`；R 的 dev 逐题结果另评一次（`runs/r9/R/eval/dev_lr_pairs.*`，不重训），不用 0a 的 test 差值代替。
  - **正收益条件**：至少一个拟放进 v9 的子任务 `Δmix` 达到最低实用收益的一半，位置 +5 个点、相对位置 +2.5 个点。"不确定"的子任务不能只凭"保住一半"放行。
  - **保住条件**：每个入选子任务 `Δmix ≥ Δpure / 2`，且 `Δpure > 0`；`Δpure ≤ 0` 的子任务不进 v9。
  - **旧任务条件**：`dev_mix` 总体准确率比 v8 降幅不超过 1 个点；按来源再看 VSR、ScienceQA、Visual7W 的分项，只报告。
  - 三条都满足才投入 v9。记录集合、基线 checkpoint、各子任务对数和两个差值，可由明细复算。
- **两条配方路径**（修订 2，评审 R9-V9-03B）：
  - **1/3 首次通过**：v9 用第四节的左右 8,000 + 回放 16,000，约 3,000 步。
  - **1/3 不通过**：再做一次 S-mix，左右 3,600 + 回放 3,600（1/2）。通过时，正式 v9 改为左右 16,000 + 回放 16,000（回放配额表不变，不删减保底），共 32,000 题、约 4,000 步、约 2 小时；仍不通过就停，记为"混合训练下未保住"，不启动 v9。
  - "不确定"减半后空出的题数转给回放，最终 YAML / MIX 的左右比例、入选子任务和回放计数以清单为准，步数和时间随之重算。

## 六、v9 验收规则（训练前写下，看到结果后不改）

| 要回答的问题 | 判断方法 | 通过条件 |
|---|---|---|
| 左右真的学会 | `test_position_flip` / `test_relation_flip` 与原题配对，按第五节口径分三个子任务算 Δ | 放进 v9 的每个子任务分别判定"有效 / 未见足够收益 / 不确定"，如实报告；至少一项"有效"才算这一轮的左右目标达成 |
| 是看图得来的 | 镜像成对表现；固定配错图映射下 `(真图准确率 − 配错图准确率)` 相对 v8 的变化，按图配对给区间 | 视觉差距的变化区间下界 > 0；配错图分数单列，不因小幅上涨一票否决 |
| 旧能力保留 | 所有 `test_*` 和四个 `bench_lv_*` 与 v8 逐题配对 | 区间下界 > −2，不事后放宽；"未证明满足保护线"与"已证明退化"分开写；计数另报与 v3 的比较 |
| 校准 | 各集合 ECE，拟合温度 | 只报告 |
| 与 laya-vision 比较 | `scripts/lv_report.py runs/v9-lr-focus/eval --prev runs/v8-vsr-v7w/eval` | 按规定生成，写进训练日志与 `laya-vision-gap.md` |
