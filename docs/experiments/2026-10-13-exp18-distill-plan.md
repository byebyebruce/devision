# exp18 方案：旧回放题加 v12 教师约束的 2,000 步小对照（待负责人批准）

日期：2026-10-13。来源：评审 EXP17-R1-03。**本文只是方案**：没有改训练代码，没有启动训练、教师推理、评测或温度拟合，也没有构建数据。实施和启动由负责人决定。不算一轮，不产出可采用的模型。

## 要回答的一个问题

同一份数据、同一批序、同一预算（2,000 步）下，**只给旧回放题加上"别偏离 v12"的约束，能不能减少旧任务的概率漂移，同时保住新计数的收益？**

依据：exp17 显示，r14 的权重方向上新计数收益和旧任务概率偏移同时存在，训练后插回 v12 能改善取舍。这里测的是"训练时约束旧任务输出"是否比"训练后统一回退"更好。这是针对本项目的设计，参考 [Learning without Forgetting](https://arxiv.org/abs/1606.09282) 的思路，不声称复刻该文的设置。**本实验不能证明蒸馏一定有效，也不能证明 RLCD 或模型容量有问题。**

## 设计：两组只差一个变量

| 组 | 说明 | 来源 |
|---|---|---|
| B（无蒸馏） | r14 数据，种子 1，到第 2,000 步 | **复用** `runs/exp16-r14-s1/stage2/monitor/step2000/`（复用条件见下） |
| D（加教师约束） | 同 B，只多一项旧回放题的教师损失 | 新训，`configs/exp18-distill.yaml`（实施时再写） |

两组共同的设置（与 exp16-r14-s1 完全相同）：
- 从 `runs/v12-ext/stage2` 开始，数据 `data/r14/train.jsonl`（81,876 题），val `data/r13b/val.jsonl`，同一套 11 个监测面板；
- 学习率 2e-5 / 1e-5 / 5e-5，warmup 300，余弦日程仍按 10,235 步计算（只训到第 2,000 步，不改日程形状），micro batch 8，MPS FP32，种子 1；
- 第 2,000 步的逐题记录写完后停止，不跑全量评测，不拟合温度。

## D 组的损失

**原有的 RLCD 和标准答案监督一题不改**，所有题照旧算 RLCD + gold 交叉熵。只在旧回放题上多加一项：

L = L_RLCD（全部题，gold，不变） + λ · (1/|B|) · Σ_{i ∈ 本批的旧回放题} KL(p_T,i ‖ p_S,i)

- **范围**：`scripts/r14/build.py:94` 定义的 `REPLAY` 五块（existence、count_original、science、general、ext）。新任务 `count_balanced`、`pixmo` 不加约束，继续只学真实 gold，不让它们模仿 v12 的计数短板。数据文件里每题已有 `block` 字段（已核对：ext 24,003、existence 10,000、general 9,998、science 7,875、count_original 6,000、count_balanced 12,000、pixmo 12,000）。
- **教师**：`runs/v12-ext/stage2` 单独加载一份，`eval()`、不求梯度、不加 RLCD 噪声。输入与学生同一个 batch（同样的 token、选项标记位置和 padding）。冻结的 SigLIP2 两边相同（加载时断言权重一致），视觉特征算一次、两边共用，教师用自己的投影层。
- **分布**：在本题的选项上做 softmax（用 marker mask 屏蔽 padding，选项按位置对齐，两边的选项顺序来自同一个输入，所以一致）。学生用**加噪声之前**的 logits。蒸馏温度 τ = 1，就是原始 logits，和发布用的校准温度无关，也不读校准温度。
- **系数与归一化（开训前冻结）**：λ = 1，只跑这一个值，不扫系数。除以 micro batch 大小 |B| = 8，而不是除以本批旧回放题数，这样一道旧回放题的 KL 和它的交叉熵在批均值里的权重相同。
- **标签问题**：gold 不改、不过滤。教师答错的旧回放题也照样加约束，因为 gold 交叉熵仍在，两项互相拉。训练中记录教师在本批旧回放题上的准确率和"教师首选 ≠ gold"的比例，只报告。
- **不用缓存**：教师在线前向，只算本批的旧回放题。按负责人"评测简单优先"的偏好，不做离线缓存和键管理。代价是每步多一次前向，见预算。

## 复用 B 的条件（实施时逐条核对，任一不满足就重跑 B）

| 条件 | 现状（2026-10-13 只读核对） |
|---|---|
| 训练代码相同 | exp16 用的提交 `4e25243` 到当前 HEAD，`src/` 没有改动（`git diff --stat 4e25243 HEAD -- src/` 为空）。D 的代码改动必须在 λ = 0 时与原路径逐位相同（见测试） |
| 数据相同 | `data/r14/train.jsonl` 修改时间 10-12 21:27，早于 exp16 开训（10-13 14:02），sha256 `f32eb217…`。exp16 当时没有记录 SHA，只能靠修改时间证明 |
| 批序相同 | exp16 的 `resume.pt` 存着全部 10,235 个批次的顺序。只用数据文件和种子 1，在 CPU 上调用 `plan_batches` 重排，**结果与之完全相同**（已验证，不需要模型） |
| 随机数用法相同 | Python `random` 只用于排批次。RLCD 噪声用 torch 在 MPS 上的随机数。LoRA 初始化在 `train()` 里 `manual_seed` 之后，消耗 CPU 随机数，所以**教师必须在调用 `train()` 之前加载**，否则 LoRA 初值会变。教师前向在 eval 模式下预期不消耗随机数（未验证）。实施时加测试：CPU 上的 tiny 模型 λ > 0 时，第 1 步的批序和 RLCD 项与 λ = 0 逐位相同 |
| 起点相同 | D 第 0 步的逐题记录应与 B 的 `step0` 相同（都是 v12，温度 1），容差为 MPS 的 1e-6 量级；不符就停下查原因 |

已知限制：MPS 上同种子有 1e-7 量级的浮点差异，两组不是逐位相同的轨迹。这和 exp16 两组之间的情况一样。

## 判定（开训前写下，结果出来后不改）

只在第 2,000 步读一次，温度 1 的逐题记录（固定口径，不受温度拟合影响）。逐题配对、按图片重采样 2,000 次。

旧任务面板 7 个：`exist`、`science`、`bind_gqa`、`ext`、`count_narrow`、`flip`、`vsr`。新任务收益面板：`count_wide`。

- **P1 旧任务保护**：7 个旧面板 NLL 之差（D − B）的等权平均，同一张图在各面板里一起进出。上界 < 0，记为"教师约束减少了旧任务的概率漂移"。
- **P2 收益保留**：`count_wide` 准确率 D − v12 下界 > 0，且 D − B 下界 > −5 个百分点。

| 结果 | 条件 | 下一步 |
|---|---|---|
| **有效** | P1 成立且 P2 成立 | 建议做一次完整 10,235 步的 D 配方，作为正式一轮；采用规则那时另写，由负责人批准 |
| **无效** | P1 点估计 ≥ 0，或 `count_wide` D − B 上界 < −5 | 不再用这种形式的蒸馏 |
| **不确定** | 其他情况 | 不自动继续，交负责人决定（如换种子重复一组） |

只报告、不改判定的项：
- 每个面板的准确率和 NLL，D − B、D − v12 各一份；
- B 在第 2,000 步漂移最明显的三项（`ext` 宏平均、存在性召回、科学 NLL）；
- `px_*` 三个 PixMo 面板；
- flip 按 596 张原图分组的复核；
- 教师在旧回放题上的准确率。

训练中不设止损：只有第 2,000 步一次监测。出现设备故障，从续训点最多重试 3 次。VSR 面板小，而且全部在温度拟合集里；本实验不用它单独作判定，只计入 P1 的等权平均，这个限制照实披露。

## 预算

- **B**：复用，0 分钟。如果复用条件不满足，重跑约 74 分钟（exp16 实测 71–74 分钟，含两次监测）。
- **D**：未实测。前 2,000 步共 16,000 题，其中旧回放 11,298 题（70.6%，按 exp16 的批序统计），平均每批约 5.6 题需要教师前向。教师只做前向，估计每步多 20–35%，D 组约 85–100 分钟，第 100 步实测后再更新。另外多一份投影层 + 决策模型（约 1.7 GB，FP32）的内存，24 GB 的机器预计够用，开训时记录 `torch_mps_gb`。
- **代码**：`TrainConfig` 加 `distill_weight`（默认 0）、`distill_teacher`、`distill_blocks`；`_items` 透传 `block`；在 `train()` 的循环里加上 KL 项；CLI 和流水线加对应参数。另写 tiny 模型的测试，覆盖随机数相容、λ = 0 时与原路径逐位相同、新任务题不受约束。估计半天。
- **报告脚本**：`scripts/exp18/report.py`，算 P1 / P2 和只报告项。

## 现在不做

- 不为了镜像关系下界 −2.11 贴线在测试集上继续扫 α，不把新的校准口径当作原规则已通过，不为完整 r14b 一直换种子直到不报警。
- 测试集已经多轮用于判断训练方向。以后的复测要披露这种适应性使用，不称为全新的独立验证。
