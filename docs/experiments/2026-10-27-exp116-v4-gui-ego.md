# exp116：exp115 + 真实手机/网页操作题 + 第一人称日常任务题（预写，2026-10-27 22:05）

**背景**：负责人 2026-10-27 定方向：优先真实场景的手机 / 网页操作数据和第一人称日常任务数据。两份数据已由后台构建：
- GUI（`data/v05/gui`，`docs/research/gui-action-data.md`）：AITW general + Multimodal-Mind2Web，截图 + 目标 + 之前的操作 → 4–6 选 1 的下一步操作；dev / test 按目标文本（AITW）和网站（Mind2Web 官方 test_website / test_domain）切分，与训练不共享。
- ego（`data/v05/ego`，`docs/research/egocentric-data.md`）：EPIC-KITCHENS VISOR 帧 → 动作（choice）/ 手接触物体（choice）/ 是否在碰某物（noul）；dev / test 按参与者切分（视频、厨房均未见）。EgoThink（604 题）只评测。

**假设**：在 exp115 配方（v0.4 + 图表 + ScreenQA UI + 计数）上加 12,000 道 GUI 动作题（Mind2Web 6,000 + AITW 6,000）和 12,000 道 ego 题（三类各 4,000），模型学会这两类新用途，且旧能力不退。

**唯一变化**（相对 exp115）：训练数据 53,048 → 77,048（`scripts/data/v05/exp116_mix.py`，seed 116）；init（v0.4）、学习率、视觉解冻、CE、1 epoch 不变；训练中监测加 GUI / ego dev 各 512 题。评测集多三个：`test_gui`、`test_ego`、`bench_egothink`。GUI / ego 的 dev、test 在混合时复制到 `data/v05/exp116/`（sha256 记在 MANIFEST），之后数据目录再重建也不影响本实验和基线。GUI 构建（run2）还在跑，接续脚本等它和 exp115 都退出后才冻结数据。

**对照**：v0.4（`runs/r21-soft`）和 exp115 在同一份 `test_gui` / `test_ego` / `bench_egothink` 上的结果（只评测 YAML `configs/{r21-soft,exp115-v4-chart-ui-count}-guiego.yaml`，接续脚本在 exp116 之前跑）；配错图（mismatched）、选项倒序对照；GUI MANIFEST 的只看文字基线（与目标词重合最多的选项：AITW test 0.44、Mind2Web test 0.42；最长选项 0.27 / 0.20；随机 0.20）。

**判据**（`devision-compare` 按图配对 95% 区间，与 v0.4 逐题配对；旧能力另与 exp115 配对）：
1. **GUI**：`test_gui` 相对 v0.4 区间下界 > 0，绝对准确率 ≥ 只看文字基线（按来源）+5pp，且配错图准确率比真图低 ≥ 5pp（真的在看图）；按来源（AITW / Mind2Web）分别报告。
2. **ego**：`test_ego` 相对 v0.4 区间下界 > 0，三类分别报告，配错图低 ≥ 5pp；`bench_egothink`（外部，未训练过）相对 v0.4 无显著退步（区间上界 ≥ 0），提升只作记录。
3. **旧能力**：MMBench / MME / CV-Bench / NaturalBench / RealWorld / What'sUp / CountBench / POPE / lv 四集相对 v0.4 无显著退步；相对 exp115 无显著退步；图表 dev ≥ 50.7%、UI dev ≥ 54.7%。
- 1、2、3 全过 → 方向成立，扩量（exp117：GUI 全量 + aitw-shopping（下载中）+ ego 全量），再定正式轮次 `r22-*`。
