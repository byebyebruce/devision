# exp26 方案：教"哪个数属于哪个面板"——面板绑定对齐，再复测 exp25（代码与测试已写，待评审，未运行模型）

日期：2026-10-16。负责人："可以啊"（exp25 之后的推荐）。不算一轮，不产出可采用的模型。

## 背景与问题

exp25（`docs/experiments/2026-10-16-exp25-read-compare-plan.md` 结果一节）：文字比较学会了（留出 0.995），图上读数没过线（dev16 0.534）。事后看明细：在 A ≠ B 的 dev16 图上，97.6% 对"A 是多少""B 是多少"给了同一个答案；读错的 90.7% 选的是另一个面板的数。模型认得出图里的数，但不按标签找面板。

这里问：**用 exp24 证明有效的那种稠密信号（补全被遮的文字）专门练"标签 → 面板里的数"，再跑与 exp25 完全相同的训练和测试，读数和图上比较能不能过线？A、B 两问还会不会给同一个答案？**

## 设计

### 阶段 A：面板绑定对齐（`configs/exp26-align.yaml`）

- 与 exp24 阶段 A 相同的对齐阶段和设置：投影层 2e-5，LoRA r16、1e-4，2 遍，batch 16，mask 0.5，warmup 100，seed 0。起点换成 `runs/exp24-align/stage1`，在已有的读字能力上继续。已 diff，只有 name、init、数据三处不同。
- 数据（`scripts/data/exp26_panels.py`，`data/exp26/MANIFEST.json`）：
  - 图用 exp21 的画法：两个面板，有字母、量名行和一个数；左右或上下排、A 在前或 B 在前都随机。
  - 说明文字固定为 "A: <量名> <数> <单位>. B: <量名> <数> <单位>."，**总是 A 先**，不管 A 画在哪边。要补出 A 后面被遮住的数，必须去找标着 A 的那个面板。
  - 每张图随机一个数值视图、一个字高（6 / 8 / 11 / 16 / 20 px）。训练 20,000 张，验证 1,000 张，两组族不重叠，像素去重。实际 A 在前 / B 在前约各半（10,157 / 9,843）。
  - 排除规则同 exp25：任何族的"量名 + 候选值"或任一视图的"量名 + 单位 + 两数（不分顺序）"都不与 exp21 的 dev 族相同（有测试）。
- 门槛：沿用 `scripts/exp24/gate.py`（留出图上混合补词的真图 − 换图差 ≥ 0.30，否则停）。这是混合文字补全的门槛，不单独证明绑定学会了，绑定看阶段 B。

### 阶段 B：exp25 原样复测（`configs/exp26-fit.yaml`）

- 与 `configs/exp25-read-compare.yaml` 只差 name 和 init（已 diff）。数据 `data/exp25/train.jsonl`（新版）、2 遍、5,002 步、设置、监测、第 5,000 步停止都不变。
- exp25（`runs/exp25-read-compare`）就是对照：同数据、同批序、同设置，只差起点。

## 判定（运行前写下，结果出来后不改；`scripts/exp26/report.py`）

- **主判定**：exp25 的结局规则和阈值，不改（读数、留出文字比较、dev16 图上比较；三态，阈值附近不当失败）。
- **对 exp25 的配对变化**（只报告）：第 5,000 步 fit、dev16 的 16 px 读数，exp26 − exp25，同题，按族重采样。
- **绑定（次要读数，运行前定下）**：在 dev16 中 A ≠ B 的图上，"A？""B？"两问答同一个选项的比例 ≤ 0.50，记为"绑定改善"（exp25 是 0.976）。另报告读错时选了另一个面板的数的比例（exp25 0.907），fit 集同样报告。

| 结果 | 可以说 | 下一步候选（另写方案，不自动启动） |
|---|---|---|
| 读数、图上比较都过线 | 在合成面板图上，这套组合设置下读数和比较都过线 | r16 正式方案：并进正式配方，补 ScienceQA temp / force，保护旧能力 |
| 绑定改善，但读数仍未过 | 不再总给同一个答案了，读数还不够准 | 加大读数训练 |
| 绑定没改善 | 这样的面板补全没教会标签 → 面板的对应 | 换绑定的训练方式 |
| 其他 | 按 exp25 的结局写 | 交负责人 |

## 已知限制

- 阶段 A 的图和阶段 B 测试用同一种画法（exp21 的面板），学会的绑定未必能推广到 ScienceQA 的瓶子 / 磁铁图。
- 单种子、一组学习率；阶段 A 从 exp24 的对齐模型接着训，等于对齐了两次。
- 不测旧能力。
