# exp92：D3 恢复训练接口探针

2026-10-25 01:05 +08:00，执行前预写。目的：在扩大恢复训练前验证固定 D3 revision 的候选映射、可微读出和导出接口。不是一轮能力训练，不将拟合结果作为泛化证据。

固定初始化 `vllm-sr/d3-lite@03560c26f5199c3c04129a2ccb38960c913635e0`，沿用现有 CUDA/uv/PIL 适配与原始问题，不添加语义后缀。从 exp81 训练文件按文件顺序选原始非翻转大小/位置各8题，每图一题，排除 exp81 protect 与 exp91 图片路径和 image_id。仅这些训练题用于工程探针，无开发/测试集调参。缓存原生 encoder 的最后位置特征，冻结全骨干，只对 FP32 255-way readout 做一次 AdamW 更新（lr=1e-5、weight_decay=0，seed92）。选项有效区间截断，与原生 softmax 温度一致；CE 为训练目标，不把它等同于校准后评测 NLL。

通过条件：复现的前向与原生 system_one 概率最大差<1e-5；梯度有限且非零；一次更新后本批 CE 下降；safetensors 导出、重新加载并注入原生 runtime 后概率差<1e-5。任何映射/非有限错误立即停，失败时保留全部产物。通过只支持读出层训练路径可用，不证明骨干可训练、恢复能力或端到端泛化。

输出 `runs/exp92-d3-training-interface/`，独占 STARTED/日志，保存输入、哈希、梯度/损失/一致性报告、单步诊断 readout；不覆盖完整原始权重。预算600秒，单卡串行。使用持久 exec 会话与600秒 timeout，记录实际退出码；非正常退出不重复覆盖。后续真正恢复训练必须接入 YAML pipeline，另写预案并固定真实数据回放、独立验证和停止门槛。
