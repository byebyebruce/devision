# exp22 方案：只训合成读数题，16 像素，r15 学得会吗——拟合测试（代码与测试已写，待评审，未运行模型）

评审 exp22 第 1 轮通过（EXP22-N01 措辞已按建议收窄）。日期：2026-10-16。负责人："我们先全力去训练模型。可以先做测试"（选 exp21 之后的选项 1）。不算一轮，不产出可采用的模型。

## 要回答的一个问题

exp21（`docs/experiments/2026-10-15-exp21-reading-plan.md` 第 9 节）里，r15 在任何字号都没学会从图里选出印刷的数字，混合批次的训练准确率全程 0.53–0.56 不升。那次合成题只占一半、每个字号只占 1/4、每族只出现一次，信号可能太稀。也可能是现在的视觉 token 根本带不出数字。

这里问：**把信号集中起来——只训合成读数题、只用最大的 16 像素、每族两个数值视图都训——r15 在 2,000 步内能不能拟合训练题？能的话，能不能推广到没见过的族？**

## 设计

- **起点与设置**：与 exp21 完全相同。r15（`runs/r15-vision/stage2`），视觉塔最上面 4 层以 5e-6 解冻，学习率 2e-5 / 1e-5 / 5e-5，warmup 100，seed 1，micro batch 8。只改数据。
- **数据**（`scripts/exp22/build.py`，`data/exp22/MANIFEST.json`）：
  - `train`：exp21 的 2,667 个训练族（同一种子重新生成，已核对与 `data/exp21/train_syn.jsonl` 的族和题目、候选、选项顺序完全相同），每族两个数值视图都画成 16 像素，三问，共 16,002 题、5,334 张图；不加回放。按 `plan_batches` 是 2,001 步，一遍。
  - `fit`：前 200 个训练族的全部训练题（1,200 题），作为 `val` 监测——它就是"训练题拟合了没有"。
  - `dev16`：exp21 dev 的 200 个未见族的 16 像素部分（1,200 题）；`dev`：同样 200 族的全部字号（4,800 题，看能否带到小字号）。
  - 对照沿用 exp21 的擦除对照和文字对照（各 600 题）。
- **监测**：第 0 / 500 / 1,000 / 1,500 / 2,000 步，每次 8,400 题。`scripts/exp22/chain.sh` 走 exp18 的链，第 2,000 步的记录写完后停止（崩溃重试，报告的退出码即链的退出码）。
- **不监测保护面板**：这是诊断，只训合成题，旧能力可能退化；本轮不测、不作采用判断。

## 判定（运行前写下，结果出来后不改；`scripts/exp22/report.py`）

只在第 2,000 步读一次，16 像素读数（readA + readB），按族重采样，阈值沿用 exp21 的筛选规则：通过 = 点 ≥ 0.80 且下界 ≥ 0.75；未过 = 点 < 0.60 且上界 < 0.65；其余为阈值附近。

| fit | dev16 | 标签 | 可以说 | 不能推出 |
|---|---|---|---|---|
| 通过 | 通过 | 拟合且推广 | 这套集中监督的组合设置（去掉回放、只用 16 像素、两个视图都训）可学 | exp21 失败的单一原因（这几处同时变了）；小字号也能学会；ScienceQA 会因此提高；通用 OCR |
| 通过 | 未过 | 拟合但不推广 | 固定的训练切片过线，未见族未过线 | 模型具体靠记忆；完全没有读数能力；读数一定学不会 |
| 未过 | — | 没拟合 | 当前配方、单遍、2,000 步下，16 像素的训练切片没过线 | 64 个 token 表达不了数字；必须做 OCR 对齐（只是候选假设，不自动启动） |
| 其他 | | 不确定 | | |

- 擦除对照在第 2,000 步读数 ≥ 0.50 或比较 ≥ 0.55：整个判定作废。
- 只报告的项：各监测步的 fit / dev16 读数轨迹；比较、两端都读对、两端都读对时的比较（附分母）、两个视图都对；dev 各字号的读数和比较；文字对照。

## 已知限制

- 单种子、一组学习率、2,000 步。"没拟合"只约束这个设置；学习率是否太低这次分不开。
- 只训 16 像素，所以小字号的结果只报告。
- fit 集是训练题本身，它的成绩是拟合度，不是推广。

## 实施（已写好，未运行模型）

- `scripts/exp22/build.py`：生成数据，复用 exp21 的生成器，不改它。
- `scripts/exp22/report.py`：复用 `scripts/exp21/readout.py` 的统计和 `fmt_stat`（n=0 输出"不可估计"）。
- `configs/exp22-fit.yaml`：`--dry-run` 通过。
- `scripts/exp22/chain.sh`：走 exp18 的链。
- `scripts/exp22/test_exp22.py`（6 项）：
  - 训练族与 exp21 相同（候选和选项顺序也相同），全部 16 像素、两个视图都有；
  - fit 是训练题的子集，dev16 与训练族不交叉；
  - 报告四种标签加作废情况，走 CLI 输出；"没拟合"时 n=0 的统计显示"不可估计"。
- 训练代码不改。数据已生成，实际训练族已核对与 `data/exp21/train_syn.jsonl` 一致。

## 预算（估计）

训练 2,001 步 × 约 1.5 秒 ≈ 50 分钟；监测 5 次 × 8,400 题 × 0.064 秒 ≈ 45 分钟。合计约 1 小时 40 分钟，最多 2 小时。
