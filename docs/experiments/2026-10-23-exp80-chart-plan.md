# exp80：真实图表决策的监督目标对照（运行前方案，2026-10-23）

执行者：Codex。状态：双臂已完成，结果与决策见末尾追加；不是可发布的一轮。

## 假设

v0.4 缺少真实图表监督；在原结构下补充 ChartQA 可以提高未见图表上的依图决策。RLCD 的策略项是否比直接 CE 更有利，使用同数据双臂区分。ChartQA 开放回答转四选一是本地诊断协议，不能称作官方开放式 ChartQA 得分。

## 数据与转换

- 来源：`HuggingFaceM4/ChartQA`（原始 ChartQA 重打包），保留 HF revision、parquet 与转换输出 SHA；许可按数据卡记录，不改项目许可。
- 官方 train 用于训练与按图片哈希划出的 5% calibration；官方 validation 用于开发，不碰官方 test。
- 是非答案只转 `noul`；单个数值或文本答案转四选一。干扰答案仅来自训练划分同类型池（年份、数值、文本），排除全部 gold 同义/数值等价项。池、选项顺序均由固定种子决定，选项不按模型表现筛选。记录随机和多数位置基线。
- validation 的干扰池也只来自 train。不是每题都有真实官方候选，因此只说明此固定四选一协议的能力。
- 图像以解码 RGB 的 SHA256 标识；validation 与 calibration 图片从 train 排除。额外使用项目现有评测的图像清单做像素去重。输出两臂共用的独立 manifest。
- 16,000 条训练呈现：8,000 图表题（不足则先拒绝，不重复凑够）+ 8,000 v0.4 来源回放，seed=80，固定后两臂逐字节相同。回放取 `data/n2/train_mix_fix.jsonl`，排除本次 calibration / validation 图像。
- 固定训练拟合切片 256 题；validation 最多 1,000 题，按图固定哈希取样；calibration 最多 512 题。小切片仅为短预算，不替代完整确认。

## 两臂

- 起点：`runs/r21-soft/train`；R=`objective: rlcd`，C=`objective: ce`。每臂 1 epoch，micro batch 8，精确 2,000 次更新。
- 两臂共用 seed 80、warmup 100、projector 2e-5 / head 1e-5 / LoRA 5e-5，SigLIP 顶 4 层 5e-6，LoRA r16；CUDA BF16；其他代码沿用现有实现。不改变分辨率/token 数。
- step0 和终点输出相同监测集合的逐题记录；主判断用 temperature=1，不以不同拟合温度制造能力收益；另报告校准后的 NLL/ECE。
- 先各用一个独立 tiny fixture 验证转换与报告规则；不修改生产训练目标。模型加载/step0失败、非有限损失、OOM均记 execution_failed，不混同配方失败。
- 每臂最多 45 分钟；达到固定更新数后自然完成。到限保留恢复文件并记 incomplete，不把截断终点当作2,000步结果。

## 预写判定

与同口径 v0.4 基线比较，按图片分组配对 bootstrap 2,000 次、seed 80：

- P1：ChartQA validation 准确率提升点估计至少 3 个百分点且 95% 下界 > 0。
- P2：终点在该集真图减错图准确率差的下界 > 0（真实视觉收益）；固定原选项与倒序的预测翻转率另报。
- P3：固定旧能力监测（`data/v5/dev_mix.jsonl` 每来源按哈希最多 64 题）没有来源下降至少 3 个百分点且区间上界 < 0；总体 NLL 增加不超过 0.05。该监测不足以宣称所有旧能力守住。
- 一臂 P1/P2/P3 全过：值得扩量；两臂全过，优先 NLL 更低且对照稳定的一臂。只有 R-C 准确率配对区间不含0时才对监督目标做方向性归因；否则优先实现简单的 CE，明示未证明目标之间有差异。
- 均不过：不扩量；报告 fit 与未见图、文本/错图对照，定位监督不足、拟合失败或视觉未利用。不得事后改成“训练集会了所以成功”。

## 限制

ChartQA 只是五类真实场景中的图表，不证明文档/UI/规划同时提升；人工转换选项可引入捷径。公开主榜的正式评分与图像隔离仍待核实。即使本实验通过，v0.5 也仍需独立确认与发布授权。

### 结论的适用范围与风险

- **重要｜真实图收益有限**：C错图43.2%而真图45.7%，P2虽通过但下界仅0.1pp；整体+14pp不能全部归因于更会看图。支持“本地真实图表选择协议可学习，终点有非零视觉收益”，尚未证明相对基线的视觉收益增量显著。下一轮保留同样真/错图对照，不能用总体涨分代替视觉证据。
- **重要｜选项顺序敏感仍在**：倒序翻转率从31.9%降至23.0%，仍可能影响真实决策；它是预写描述指标，不临时改为本轮通过门槛。后续候选继续报告翻转率及概率变化，必要时单独做换序监督对照。
- **重要｜概率与泛化仍待验证**：本轮calibration仅512道图表题（noul很少），不是跨域发布温度；R在旧保护上的校准后NLL0.6573，高于自身T=1的0.5782。正式候选需独立混合域校准及旧/新域概率回归。本地ChartQA四选一得分不能当成官方开放回答成绩，也不能替代五用途或ImageJevBench Capability。
- **阻断发布｜主榜证据缺失**：完整公开300题未取得，官方8例仅作冒烟；score协议仍需设计/验证。发布门槛保持原目标，不通过换指标规避。
