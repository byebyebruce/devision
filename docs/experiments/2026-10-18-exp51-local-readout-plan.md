# exp51 方案：EXP50 实际局部 SigLIP 特征的数值读出（T / C；CPU 准备完成，未运行，等评论家的模型许可）

日期：2026-10-18。依据：评论家 EXP51-PREP-01（EXP50 终点之后）。

## 问题

EXP50 交给 QuestionConditioning 的那些局部 patch，在已知字段区域（oracle）时，能否支持对未训练图的整串数字读取？保留原始细节（T）与降到全图细节（C）是否不同？结果决定下一步应投入"数值内容 / 选择路径"，还是重新处理真实输入的可读性。不重测 projector；读出头不是产品候选。

## 固定对象

- **视觉塔**：EXP48-X、EXP50-T、EXP50-C 的 SigLIP 逐张量相同。`scripts/exp51/vision_identity.py` 只读 safetensors 头和 `vision.` 张量的原始字节，三者都是 208 个张量、371,721,216 字节，sha256 `11301272…`。提取时从 EXP50-T 的冻结终点（`1a8e5439…` / `99c6246e…`）加载，eval / no_grad。
- **两个条件只差像素来源**：用真实产品路径 `image.local_pixels(图, 256, 12, 0.25, source)` → `model.visual_inputs`，取条件模块投影前的 K/V（全图 256 个 patch，再依次是 12 个视图的 patch，共 3,328 个）。
  - T：source "T"；C：source "C"。
  - 不另裁紧框、不重绘、不提高分辨率。
- **题单**：`data/exp49/questions.jsonl`（`80943a63…`），4,752 题、1,760 张图。
  - fit_O + fit_L 共 1,152 题训练读出头；rl_tune / rl_tune_L 全部读出；
  - 不挑子集，不按结果选步；
  - 15 个切字题（EXP50 几何）只单独报告。

## 区域（`scripts/exp51/regions.py` → `data/exp51/regions.json.gz`，`fe9b81b3…`；无模型）

- **不退回全图**：每题用稳定的字段框（EXP45 已核的行框 [x, y, w, h]）。全图和 12 个视图中，凡 patch 与"视图内容区 ∩ 字段框"有正面积相交的，都保留为单独的 token，按 visual_inputs 的平铺顺序（视图 × 256 + patch）。
  - 灰边不算内容；重叠视图的特征不平均。
  - 不按数字内容或长度换框。
- **每个 token 的位置信息**：
  - 同一视图内相对首个选中格的 (行, 列)，在 0..15 之内；
  - 原图坐标下相对字段框的连续几何 ((cx − bx) / bw, (cy − by) / bh, pw / bw, ph / bh)；
  - 视图编号只作记录，不输入读出头。
- **全量检查**（从实现复核，不引用评审的草算）：
  - 每题 token 数：fit_O 104–436（均值 176.2），fit_L 31–305（125.0），rl_tune 72–436（176.9），rl_tune_L 42–307（123.3）；共 713,844 个。
  - 没有空区域，每题都含全图 token；每题涉及 2–8 个视图。
  - rel 全部在 0..15 之内。
  - 同图异目标的输入碰撞：0。
  - 2,808 个值改变的孪生（供体）的索引、视图和 float32 几何全部相同。

## 读出（`scripts/exp51/probe.py`，复用 `scripts/exp49/probe.py`）

- **头和训练**：EXP49 的头、损失、严格字符解码，训练固定为 seed 0、AdamW 1e-3 / wd 0.01、batch 64、1,000 步、取最后一步。每个条件一个独立同构的头。批内只 pad 到本批最长。
- **供体**：题 i 的标签配孪生的特征，保留 i 自己的 rel、几何和 mask。运行时再核一次供体区域相同，不同就拒绝。
- **统计**：EXP49 的读出（整串各字段 / 宏平均、字符、异值两对象、改变值孪生、同答、真减供体及区间、跟随供体）。
- **条件**：
  - 有效性：fit_L 宏平均 ≥ 0.90、每个字段 ≥ 0.75；对原图另加 fit_O 同样的门槛（fit_O 没学好时，原图低分记为"未定位"）。
  - 投资：tune_O / tune_L 的宏平均 ≥ 0.80、每个字段 ≥ 0.60、两对象 ≥ 0.50、孪生 ≥ 0.50、真减供体 ≥ 0.20 且下界 > 0。
- **原始细节归因（预写）**：rl_tune 整串宏平均 T − C ≥ +0.10，按 case 簇重抽（2,000 次，seed 0）的下界 > 0，且 T 自身的原图投资条件成立。fit_O、fit_L、tune_L 的 T − C 也一并报告。
- **分支（预写，评论家 EXP51-PREP-01）**：
  1. T 原图达到投资条件且归因成立：局部内容在 oracle 区域下可读，并可归于原始细节。下一项主模型实验优先给局部内容读出直接监督，再训练问题选择 / 决策。
  2. T 和 C 都有原图正证据、归因不成立：可以准备内容 / 选择路径，但收益不归于原始细节；先考虑更便宜的可读输入路径。
  3. 头有效、原图都未达到：只否定这次固定读出条件，不宣布视觉塔不可读；不接长的 12 视图候选训练。
  4. 头没学好或有缺项：未定位；不换头、不加步、不改阈值、不重试。
- **可复算**：逐题明细（真读和供体）在算区间之前写出；`--recompute` 只用明细重算全部读出、条件和分支；头权重和特征、题单、区域、模型的身份都保存。

## CPU 验证（`scripts/exp51/test_exp51.py`，6 项通过；pyright 0 错误）

- 区域 token 与 0.5 像素格上的暴力相交结果完全相同；rel 从同视图首格起算；几何相对框；灰边区域不产生 token。
- tiny 模型：收集到的 token 等于 visual_inputs 的 K/V 在这些索引上的值，也等于对应视图 letterbox 单独过塔的 patch；T 和 C 的全图 token 相同，视图 token 不同。
- 供体只替换特征，区域不同时拒绝。
- 视觉身份：决策部分可以不同，视觉张量差一个字节就拒绝。
- 条件、归因和分支：完美 / 全错预测下的结果；只有一个条件时为 incomplete；切字切片计数正确。
