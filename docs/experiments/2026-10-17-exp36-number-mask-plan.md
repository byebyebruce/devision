# exp36 方案：完整数值遮罩的同预算对照（评论家 EXP36-RUN-01 放行，已运行一次，结果见文末：继续条件都不满足）

日期：2026-10-17。依据：评论家 EXP35-RESULT-01、EXP36-PREP-01 / READOUT-01 / BUDGET-01。

exp35 显示，exp32 的 A2 末点不能按图补出被问的数值：
- 完整数值遮罩下，整个数字补对的只有 2–7%；
- 两对象、孪生两视图同时正确都是 0。

数值 token 只占随机遮罩 token 的 19%，但在终点 tune 真图评估里占了 NLL 总和的 97.64%。所以"token 少、loss 被稀释"不能当作已确认的根因，不靠给数字加权。这里要检验的是：去掉"其余数字片段 / 另一边可见数值"这类文本捷径，让训练真正覆盖完整数字的补全，能不能学会按图读数。

## 要回答的问题

**从同一个 A2 末点、同样的数据和步数出发，只把真实版式说明文字的遮罩从"随机 0.5"换成"两对象的全部数值都遮住、只监督数值"，完整数字补全和标签绑定能不能明显好于继续原样训练？**

## 两臂（只差遮罩策略）

| | A（对照） | B（实验） |
|---|---|---|
| 配置 | `configs/exp36-a.yaml` | `configs/exp36-b.yaml` |
| 真实版式说明文字 | 原随机遮罩 0.5 | 两对象的质量 / 速度 / 距离全部数值 token 都遮住，并且只监督这些 token；标签、量名、单位保留 |
| COCO 说明文字 | 原随机遮罩 0.5 | 同 A |

- **共同部分**：
  - 起点：两臂都从 `runs/exp32-align/stage1`（sha256 `8476145e…e297`）各自独立起跑，B 不接着 A 训。
  - 设置：batch 16、max_caption_tokens 44、投影层 2e-5、LoRA r16 / alpha 32 / 1e-4、warmup 100、seed 0、一轮余弦。视觉塔、决策头、MLM 头的冻结方式不变。256 输入、64 个视觉 token、字号、图像、说明文字、标签都不变；不改损失权重，不加决策 CE 或 RL。
  - 两份 YAML 只差 `name` 和 `number_mask_sources`（已 diff）。两臂都记录 `track_sources`：真实版式温度、磁力和其余来源各自被监督的 token 数及占 batch 损失的份额。
- **数据**（`scripts/exp36/build.py` → `data/exp36/`）：
  - 从 real_layout 的训练说明文字（`e8120b52…`）按 seed 36、以族为单位抽温度 2,000 族、磁力 2,000 族，保留两张视图，共 8,000 张图；
  - 从 exp32 A2 混合文件（`da011a1b…`）的 12,000 张隔离 COCO 图中抽 8,000 张；
  - 混合打乱后共 16,000 行（`912a9cd2…`），一遍正好 1,000 步。
  - 不重画、不扩来源；tune / confirm、exp31 和新确认集都不进入。train 和 tune 在生成时已按规范案例隔离。
- **实现**（`src/devision/train/align.py`，默认关闭，开启时只作用于指定来源）：
  - 先照常抽随机遮罩，消耗同样的随机数；再只改写指定来源的那几行：数值跨度的 token 遮住并作为唯一目标，其余 token 可见、不作目标。所以两臂的数据顺序、说明文字选择、COCO 遮罩和之后的随机流完全相同。
  - 数值跨度用 `number_spans`，规则与 exp35 已核的相同（12,600 条说明文字的跨度逐条一致）。
  - 缺少应有的字段（温度 4 个数、磁力 2 个数）、数字被截断或没被完整覆盖时直接报错，不静默跳过。

## 读出（运行前写下，不改；`scripts/exp36/readout.py`、`report.py`）

- **主评测**：600 张旧 tune 图。两臂末点都跑 exp35 的两个条件：
  - 原随机遮罩只用于复现和分项，不再当能力门槛；
  - 完整数值遮罩，真图和同一张固定换图（批内轮转一位，不改）。
- **固定训练切片**：从已选训练族中按 sha256(族 id) 取温度 50 族、磁力 50 族，共 200 张，两视图相邻（`fit_slice.jsonl`，`63221c65…`）。只读拟合程度，不与 tune 混算。
- **逐数记录**：同一次前向，每个数字记 sample / family / field / object、gold token、预测 token、整数是否全对、展示图身份、遮罩条件，不增加前向。
- **统计**：
  - 按族配对重采样（seed 0，2,000 次，同族两视图和所有字段一起抽）。
  - 每臂：整个数字准确率（按字段及等权宏平均）；异值两对象同时正确（及宏平均）；数值变化的孪生两视图同时正确，并给出分母。
  - 图像依赖：只取"换图恰是本项的孪生图、且这个 field / object 的数值确实变了"的数字，比较真图 − 换图的整数准确率，按族给区间（纯报告过滤，不加模型调用）。
- **值得继续完整数值路线的条件**（只用来决定是否继续投入训练，不是交付达标），四条全部满足：
  1. B − A 的整数宏平均 ≥ +0.10，且配对区间下界 > 0；
  2. B − A 的异值两对象宏平均 ≥ +0.10，且下界 > 0；
  3. B 的质量、速度整数准确率各 ≥ 0.20；
  4. B 在上面的孪生过滤集上，真图 − 换图的下界 > 0。

  只有距离单项或模板总分上涨，不能替代这些条件。
- **保护**：两臂末点各评 7 个面板，对 v0.3 按原代价规则报告，复用 v0.3 的记录。与数值终点分开报告，不因为起点就有代价而否定数值可学，也不豁免最终候选的保护门槛。
- **不评**：rl_confirm、75 题属性、80 题 ChartQA；不跑全量 bench，不调温度。
- **分支**（由评论家看结果决定，不自动启动 B 阶段或 exp33 / 34）：
  - B 满足条件 → 继续这条对齐路线，再接含旧决策回放的受控决策训练；
  - A、B 都改善但差异不足 → 不宣称是全遮特有的收益；
  - 只在 fit 切片上好、tune 上差 → 泛化不足；
  - 两臂都低 → 下一项优先做"同样 256 输入下只放大目标数字"的可读性对照，另写方案。

## 预算（EXP36-BUDGET-01）

| 部分 | 估计 |
|---|---|
| 两臂各 1,000 步（A2 实测约 2.1 秒 / 步，含每 500 步的 val） | 约 72 分钟 |
| 数值读出：每臂 tune 600 + fit 200（exp35 实测 600 张 157 秒） | 约 8 分钟 |
| 7 个保护面板 × 2 臂（exp30 实测同样面板约 8 分钟 / 臂） | 约 16 分钟 |
| 合计 | 约 96 分钟 |

- `scripts/exp36/chain.sh` 用一个 2 小时绝对截止（`runs/exp36.deadline`，重启沿用），涵盖加载、训练、评测和报告。每一步都在 `capped` 下运行：到点对进程树发 TERM，15 秒后发 KILL（复用 exp35 的 guard.sh）。失败不重试，不自动接 B 阶段。
- 启动前确认没有其他模型进程，并核对 A2 的 sha。每个 run 保存有效配置、数据哈希、起点、代码版本、实际的遮罩策略，以及梯度和损失趋势（SwanLab 加 `track_sources` 份额）。
- 命令：`nohup bash scripts/exp36/chain.sh > runs/exp36.out 2>&1 &`，评论家放行后才运行。

## CPU 验证（已做）

- `tests/train/test_align_numbers.py`（3 项）：
  - 用 checkpoint 的 tokenizer：只有指定来源的行被改写；改写后随机流和 COCO 行与原来逐位相同；被遮 token 恰好解码为两对象的全部数字，Pair / Sample 编号和单位都不在目标里；
  - 缺数字的说明文字和 COCO 文字被拒绝；
  - 数据里没有指定来源时，tiny 模型的逐步损失与原路径完全相同。
- 对全部 12,000 条训练和 600 条 tune 的说明文字逐批改写，全部通过；跨度与 exp35 的规则逐条相同（12,600 / 12,600）。
- `scripts/exp36/test_exp36.py`（2 项）：抽样保留同族两视图、16 行 × 1,000 步的结构、fit 切片取自已选族；统计的分母、孪生过滤和族配对区间。
- exp33 的 align 测试仍通过；两份 YAML 都 dry-run 通过，只差遮罩策略。

## 已知限制

- 单种子；每臂 1,000 步可能不够看出差别。阈值只用于决定是否继续，不是发布判据。
- B 的训练分布（只遮数字）和 A 不同，也和 exp35 的诊断条件更接近，这在解释时要注意。
- 一个数字占几个 token 本身可能泄露数值，所以以真图 − 换图的差为准。

**读法**（只限这次的设置；按评审 EXP36-RESULT-02 收窄）：
- 全遮监督提高了完整数字补全（tune +0.068 [+0.042, +0.095]，fit 0.143 → 0.247），但还没有建立随数值变化而正确读数 / 绑定的能力：异值两对象、孪生两视图同时正确几乎为 0，没有达到任何继续条件。
- 不能说模型完全不响应像素：在"目标值确实变了、换图恰是孪生"的 414 个数里，B 有 255 个（61.6%）真图和换图的预测不同（A 是 206 个），只是变得不对——真图对 26 个、换图对 29 个，同时对 14 个。fit 切片的依图差 +0.037 [−0.019, +0.101] 没有确认正收益，但也不能断言为 0；fit 只训练了一次 1,000 步，不是充分的过拟合实验，不能排除泛化和优化共同受限。
- 换成别族的图，同时改变了对象、颜色、几何和布局；孪生图也会随质量改变粒子半径、随距离改变磁铁间隙。所以"利用版式 / 题型等粗线索"只是一个解释假设，不是唯一根因。仍分不清是字形可见性、区域对应还是优化不足。
- 按预写的分支属于"两臂都低"：下一项是 exp37，同样的 256 输入下做数字大小的可读性对照（评论家 EXP37-PREP-01）。两臂都不进入 v0.4 候选。
