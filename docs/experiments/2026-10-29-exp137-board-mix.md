# exp137-board-mix：榜单短板数据（Winoground 式 caption、KIE、InfographicVQA）混入 r23 配方（预写 2026-10-29 12:10）

**目的**：验证 `data/v05/board/` 里已就绪的三类数据各自对 Decision Index 公开视觉榜的对应短板有效、旧能力不退，作为 r24 的数据依据。只评不训的榜单题永远不进训练（builder 已按图片哈希排除全部榜单图片，见各 MANIFEST 的 `board_exclusion_hits`）。

**改动**（只改数据，其余与 r23 完全相同：从 v0.4 `runs/r21-soft/train` 起、seed 2323、lr_vision 5e-6、1 epoch）：`scripts/data/v05/exp137_mix.py` → `data/v05/exp137/train.jsonl` = r23 的 `data/v05/exp132/train.jsonl`（205,166）+
- caption（Winoground text 子任务）：COCO train2014 一词替换 / 交换的难负例 caption 二选一，按图每图 1 题抽 20,000；
- kie（KIE CORD+FUNSD）：字段值选择 + 字段是否填写，7,402；
- infographic（InfographicVQA）：Cauldron 训练集，同图答案作干扰项，5,733。
共 238,301 行（+16%）。每类的 dev（族内按图留出，与训练图不重叠，脚本检查）复制为 `dev_board_{caption,kie,infographic}`。深度（56 题）、hateful memes、DocVQA / ArxivQA 尚未就绪，不在本实验。

**对照**：r23（同配方同种子、没有这三类数据）；另记 v0.4。v0.4 和 r23 在三个 dev 上另跑只评测 YAML（`configs/exp137-{v4,r23}-boarddev.yaml`）。

**判据**（预写，按图配对 95%）：
1. **每类有效**：该类 dev 上 exp137 对 r23 下界 > 0；且 Decision Index 对应基准（Winoground / KIE / InfographicVQA）skill 对 r23 点估计上升。两条都满足的类进入 r24；只有 dev 涨、榜单不动的类记为「学到了本族分布但不迁移」，r24 不加量。
2. **旧能力不退**：r23 的 33 集上，exp137 对 r23 没有显著退步 > 1 点的集合（新用途五集同样适用）；有则列出，r24 对相应类减量或加回放。
3. 校准：dev 与 33 集 ECE 不劣于 r23 超过 0.01。

**归因限制**：三类同时加入，单类效果只能用各自的 dev 和对应的榜单基准分开看；对旧能力的影响不能拆到单类，若判据 2 不过再做单类消融。

**预算**：`scripts/v05/chain_exp137.sh 773215`（挂在 r23 链之后；r23 链是当前唯一一条链）：r23 榜单全量（GPU，约 30–40 分钟）→ 两个 boarddev 只评测（约 10 分钟）→ exp137 训练（29,788 步，约 90 分钟）→ 36 集评测 + 对照（约 150 分钟）→ lv_report 与配对 → exp137 榜单（约 30–40 分钟）。r23 预计 15:00 前后评完，本链预计 20:30 前后结束。日志 `runs/v05-chain/chain_exp137.log`。

## 中期（2026-10-29 16:30，19 / 36 集评完，榜单未跑）

- **准确率（对 r23，按图配对 95%）**：dev_board_caption **+10.2** [+8.1, +12.4]、dev_board_kie **+13.4** [+7.7, +18.6]、dev_board_infographic +4.9 [−0.4, +10.1]（不显著）；旧集合无显著退步，EgoThink +2.8、MMBench +0.8、test_ego +1.3、test_gui +2.0 显著上升，最差 ChartQA −0.7 [−2.6, +1.0]。

- **修复**：`MIN_TYPE_ITEMS` 10 → 50（与分桶的 `MIN_BUCKET_ITEMS` 一致），少于 50 题的题型不拟合、训练时回落到 1.0；exp138（同一拟合集）开训前生效。
