# exp16：同种子配对短程，分开 r14b 的数据替换和训练轨迹

日期：2026-10-13。负责人选"赶紧动手的方案"，即评审 R14-R1 第 1 轮的 A 方案：两个配方用同一个新种子，各训到预定的短程检查点，再做同题比较。读法在训练前写下，结果出来后不改。不算一轮，不产出可采用的模型。

## 要回答的问题

r14b-mirror 在第 2,000 步被原格式计数面板止损：对 v12 −3.3 [−6.3, −0.7]；对 r14 同一步直接比较 −2.67 [−6.67, +1.00]。止损原因有两个候选，单看种子 0 分不开：

- 数据替换：+2,000 镜像对、+1,000 VSR、−3,001 扩展回放；
- 换数据后的批次顺序和随机波动。

## 设计

| 组 | 数据 | 种子 | 配置 |
|---|---|---|---|
| exp16-r14-s1 | `data/r14/train.jsonl`（81,876） | 1 | `configs/exp16-r14-s1.yaml` |
| exp16-r14b-s1 | `data/r14b/train.jsonl`（81,875） | 1 | `configs/exp16-r14b-s1.yaml` |

- 其余参数与 r14 / r14b 完全相同，包括学习率、warmup 300、按 10,235 步的余弦日程。
- 种子同时决定数据打乱顺序和 RLCD 噪声。
- 两组用同一套 12 个监测面板（含 `flip`、`vsr`）。
- 第 2,000 步的逐题记录写完后，由 `scripts/exp16/chain.sh` 停止训练；不跑全量评测，也不按止损规则提前结束。两组先后跑，预计约 2.5 小时。

读数由 `scripts/exp16/report.py` 产生：
- 每个面板上 r14b − r14 在第 2,000 步的差值，种子 1 一份、种子 0 一份（r14-count / r14b-mirror 已有的明细；种子 0 的 r14 没有 `flip` / `vsr` 面板）；
- 两个种子合并的差值：按图片重采样，同一张图在两个种子里一起进出；
- 种子 1 的两组各自按 r14b 冻结的止损规则对 v12 判一次，只报告。

## 读法（训练前写下）

主读数：**原格式计数面板 `count_narrow`，两个种子合并的 r14b − r14**。

1. **替换伤计数**：合并差值 ≤ −2 个百分点，且上界 < 0。
   - 结论：按这次的构建方式，用镜像对和 VSR 替换扩展回放，会在早期伤到原格式计数。
   - 下一步：不照原样再训完整的 r14b。若还要补左右能力，改用 B（只追加、不削减）或同批配对，作为新变量，开训前预写规则。
2. **未检出**：其他情况。
   - 结论：现有证据不能把 r14b 的止损归因于数据替换。
   - 下一步：负责人可以决定用新种子重训完整的 r14b 配方，止损和采用规则不放宽。
3. **只报告、不改变上面的判断**：
   - `flip`、`vsr` 面板在种子 1 上的 r14b − r14：下界 > 0 时写"早期已见改善"，否则写"未检出改善"；
   - 其余面板的合并差值；
   - 种子 1 的 r14 组是否也触发止损规则。若触发，说明这条规则在第 2,000 步对训练轨迹敏感，这个信息交给负责人和评审，用于讨论之后的规则，不回头改 r14b 的判定。

## 已知限制

- 只有两个种子，估计不了训练方差的分布。
- 只看第 2,000 步，不代表训完时的结果；r14 自己在第 6,000 步到过 −1.7，之后回升。
- 镜像对没有同批训练（评审 R14-R1-N03），本实验不检验同批配对。
- 按负责人"赶紧动手"的要求，未先请评审审设计。

## 结果（2026-10-13 16:27）

| 时间 | 组 | 情况 |
|---|---|---|
| 14:02 → 15:16 | r14 组 | 跑到第 2,000 步 |
| 15:16 → 16:27 | r14b 组 | 跑到第 2,000 步 |

两组都没有故障和重试。读数见 `runs/exp16/report.txt` / `report.json`（`scripts/exp16/report.py`）。

### 主读数：原格式计数，r14b − r14（第 2,000 步，单位为百分点）

| | 差值 [95%] |
|---|---|
| 种子 1（本实验） | −0.3 [−3.7, +3.0] |
| 种子 0（r14b-mirror / r14-count） | −2.7 [−6.7, +1.0] |
| **两个种子合并** | **−1.5 [−3.5, +0.7]** |

**判定：读法 2「未检出」。** 合并差值没到 −2，上界也不 < 0，现有证据不能把 r14b 的止损归因于数据替换。种子 1 的 r14b 组对 v12 的原格式计数是 +0.0 [−4.0, +4.0]，同一个配方换了种子就没有触发止损。

### 只报告的项

- **镜像对 / VSR**（只有种子 1）：
  - `flip` +0.6 [−0.8, +2.0]，`vsr` +2.1 [−1.5, +5.8]。
  - 下界都不 > 0，记为**未检出改善**；点估计方向和种子 0 相反（种子 0 是 −0.3 / −1.4，但那是对 v12 的比较，不是对 r14）。
- **其余面板的合并差值**：

  | 面板 | 合并差值 [95%] |
  |---|---|
  | 完整候选计数 | −2.0 [−4.8, +0.8] |
  | 存在性 | +0.4 [−0.1, +1.0] |
  | 科学 | −0.4 [−1.7, +0.8] |
  | 绑定 | −0.4 [−1.4, +0.7] |
  | 扩展 | −0.1 [−0.9, +0.7] |
  | PixMo 窄候选计数 | −1.0 [−3.8, +1.9] |
  | PixMo 存在性 | +0.5 [−3.0, +3.8] |

  区间都含 0。完整候选计数的点估计偏负，值得在完整训练中留意。
- **种子 1 两组按 r14b 冻结的止损规则对 v12 判定**：都**不止损**。

  | 组 | 原格式计数 | 扩展宏平均 | 存在性召回 | 科学 NLL |
  |---|---|---|---|---|
  | r14 组 | +0.3 [−2.3, +3.3] | −1.3 [−2.5, −0.1] | −1.1 [−2.4, −0.3] | +0.086 [+0.027, +0.139] |
  | r14b 组 | +0.0 [−4.0, +4.0] | −2.1 [−3.5, −0.8] | −1.9 [−3.5, −0.6] | +0.020 [−0.033, +0.066] |

  两组的扩展宏平均和存在性召回都下降，但都没到 −3 的止损线。r14 组的科学 NLL +0.086 接近 +0.1 的线（该规则要连续两次才止损）。

### 解读

- 同一个 r14b 配方，种子 0 在第 2,000 步止损（原格式计数 −3.3），种子 1 不止损（+0.0）。这说明这条规则在第 2,000 步的判定会随训练轨迹变化；**不能**据此说种子 0 的止损是误报，种子 1 不报警也不证明替换安全。只有两个种子，估计不了它的误报率。（2026-10-13 按评审 EXP17-R1-02 修订。）
- 数据替换对原格式计数的合并效应是 −1.5 [−3.5, +0.7]，没有证明有伤害，也没有证明没有伤害。这个区间只反映这两次固定训练结果上的图片抽样不确定性，不含训练种子之间的方差。
- 镜像对和 VSR 在第 2,000 步还看不到改善。
- 按读法 2，下一步由负责人决定：可以用新种子训完整的 r14b 配方，止损和采用规则不放宽。不回头改 r14b-mirror 的判定。评审（EXP17-R1-03）不建议仅凭这个结果优先重跑完整 r14b，下一步改为准备旧任务蒸馏小对照（`docs/experiments/2026-10-13-exp18-distill-plan.md`）。
