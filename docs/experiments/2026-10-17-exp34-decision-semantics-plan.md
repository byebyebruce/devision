# exp34 分支记录（草案）：决策语义监督——数值比较、标签指向、强弱正反问法、相等配对（未实现、未运行）

日期：2026-10-17。依据：评论家 EXP31-RESULT-01。exp31 显示，磁力题在纯文字里就失败了：
- 只比两个数：v0.3 非相等题 0.244（低于随机水平），70% 的回答选"相等"；exp26B 0.067，93% 选"相等"；
- 找更近的一对：exp26B 0.075；
- 给出规则后，两种问法都答对的比例只有 0.050 / 0.067。

旧的 exp25 文本模板比较能到 0.995，但这个能力没有迁移到新的问法、单位和候选写法。

本文只记录这个分支，用于 exp32 之后的选择。**触发条件**：exp32 的真实版式读数已经能读出（rl 调参 / 确认集的读距离、读质量 / 速度明显高于 v0.3），但 ScienceQA 式问题仍然答错。exp32 若连读数都没提升，先解决读数，不做本分支。

## 要回答的问题

**决策训练里加入"数值 → 关系 → 指向 → 措辞"的成对监督，并且相等与不相等平衡，能不能让模型在没见过的数值案例上答对比较题，而不退回"选相等"或"选 Pair 2"？**

## 数据（新生成；与 exp31 和诊断案例不重合）

都放在空白图上，数值写在文字里，与 exp31 的问法分开出题。按族生成，一个族就是一个 canonical 数值案例，所有视图同族放进同一个 micro batch（`group`）：

| 层 | 内容 | 视图 |
|---|---|---|
| 数值比较 | 两个带单位的数：小于 / 大于 / 等于；也问"哪个更大 / 更小" | 交换两个数的顺序，措辞和选项排列不变 |
| 标签指向 | "Pair 1 / Pair 2"、"Sample A / B" 各自对应一个数，问哪个标签的数值更大 / 更小 / 一样 | 交换标签与数值的对应 |
| 规则 + 强弱问法 | 磁力：越近 / 越大越强；温度：M·V² 越大温度越高。同一案例分别用强说法（greater / stronger / higher）和弱说法（smaller / weaker / lower）问 | 强弱各一，再交换对象 |
| 相等配对 | 每层约 25% 的族数值相等，与一个只改一个数的不等族配对 | 相等不随交换改变 |

- **隔离**：
  - 排除 exp31 的全部 canonical 案例（单位, 无序数值对 / 大小组合），以及 24 道诊断转录案例；
  - 也排除 exp32 real_layout tune / confirm 的规范案例；
  - 值域和单位沿用 real_layout 的扩展取值表，但 canonical 案例另行划分 train / tune，互不交叉。
- **规模（待定）**：约 4,000 题。混入 exp32 式 B 的决策数据，替换部分 exp25 合成面板题，保持总步数和旧决策回放的比例不变。
- **监测**：exp31（600 题，只作监测，绝不进训练）、ScienceQA 温度 / 磁力开发题、real_layout 调参集、7 个保护面板。

## 设计要点

- 起点和其余设置都与当时被选中的候选配方相同，只多这一块数据，这样提升可以归于这块数据。若要同时改起点，就不能称单因素收益。
- 损失沿用 B 的 RLCD + gold CE。评论家指出，当前结果不能证明换一种强化学习算法就能解决问题。如果以后要比较纯 CE 和 RLCD，另立对照：固定起点、数据、预算，不混进这一分支。
- 判定（实施时写进方案，开训前冻结）：
  - 主读出是 exp31 a 层非相等题的准确率，以及"预测指向的分布与 gold 接近"——不能一边倒地选"相等"或"Pair 2"；
  - c / d 层两种问法都对的比例；
  - ScienceQA 磁力 / 温度开发题对当时基线的变化；
  - 7 个面板的预写代价。
