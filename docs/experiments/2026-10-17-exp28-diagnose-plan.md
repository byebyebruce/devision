## 要回答的四个问题

exp27（`docs/experiments/2026-10-17-exp27-transfer-plan.md`）：exp26 第 5,000 步在真实温度 / 磁力开发题上比 v0.3 更差，加权准确率 −11.1 [−20.1, −2.1]，6 个保护面板下降。修订后的事后观察：

- 温度题给出转录数值后 10 / 12 正确（原图 3 / 12）；
- 磁力题给出文字也只对 3 / 12；
- 合成擦除图上 186 / 200 选"相等"，补上数值后 198 / 200 正确。

这里要问：

1. **阶段**：旧能力下降、真实题上"选相等"，分别从哪个阶段开始？比较的是现有端点 v0.3 → exp24-A（读字对齐）→ exp26-A（面板对齐）→ exp26-B（第 5,000 步）。
2. **评测路径**：exp27 导出的模型，用 `decide` 答题，能不能复现 exp26 自己第 5,000 步监测记录里的合成题答案？这一步排除导出或推理路径出错。
3. **温度 / 磁力卡在哪一步**：模型能不能直接从真实图里读出 A、B 的质量、速度和两对磁铁的距离？磁力题如果给出通用规则（不含本题数值和答案），能不能答对？
4. **"相等"的措辞和顺序**：把"相等"选项换成同义的另一种说法，并把三个选项循环换序，答案会不会变？

## 判定（运行前写下，结果出来后不改；`scripts/exp28/report.py`）

**阶段 × 能力表**：每个端点给出温度 / 磁力（真图、错图）、浓度、吸斥的准确率，温度 / 浓度上选"相等"的比例，7 个保护面板的准确率。三个后续端点还要与 v0.3 配对：

- 迁移：沿用 exp21 / 27 的 68 : 114 规则；
- 保护代价：≤ −3 且上界 < 0；ext 用宏平均，flip 镜像并到原图。

由此定出：
- **旧能力最早下降的阶段**：最早出现 ≥ 2 个代价面板的端点；
- **"选相等"最早出现的阶段**：温度或浓度上选"相等"的比例最早 ≥ 0.5 的端点。

**各项诊断**：

| 项 | 规则 |
|---|---|
| 评测路径（control30） | 把 `decide` 的概率按导出模型的温度还原到温度 1，和第 5,000 步监测记录逐题比较。top-1 不一致、且监测记录前两名的差 ≥ 0.001 的题，至多 2 / 90 才算通过；另报告最大概率差 |
| 温度直读（fields，exp26B，48 题） | 准确率 ≥ 0.80 **且**真图比空白图的同题配对收益下界 > 0 算"读得出"；准确率 ≤ 0.60 算"读不出"；其余（含高准确率但看不出看图收益）为不确定。另报告空白图准确率和读错时选了另一个对象的值的次数 |
| 磁力规则（force_rule，exp26B） | 加规则后 ≥ 9 / 12，且原转录文字 ≤ 4 / 12 → "规则缺失"；加规则后 ≤ 5 / 12 → "规则也没用" |
| 措辞（equal_wording，exp26B） | 改写后"相等"占比下降 ≥ 0.25，且同题配对的准确率变化下界 > 0 → "依赖答案措辞"；另报告三种顺序各自的准确率 |

**下一项修复**：按下面的优先顺序只选一项，结果出来后据此写方案，不再交给负责人选方向：

1. 评测路径不通过 → 先修导出 / 推理路径，其他结果都不解释（回放位置和磁力附注也标为"待定"，评审 EXP28-R1-01 的 Spec 条件建议）。
2. 温度直读 ≤ 0.60 → **从合成面板到真实版式的读数 / 属性绑定桥接**：逐步加入多属性、标签措辞和布局变化，用新的训练图，不用这批诊断图；保留合成任务做回归检查。
3. 磁力"规则缺失" → **关系规则、正反向问法和候选语义的训练**；单纯重画磁铁不算修复。
4. 依赖答案措辞 → **同义措辞一致性**的修复，并验证同义说法下答案一致。
5. 温度直读算"读得出"（≥ 0.80 且有看图收益）→ **在真实版式上练"读到的字段 → 作答"的组合**。
6. 其他 → 证据不能区分，如实写明。

另有两条附加规则：

- **回放放在哪**：随下一项修复一起定下。旧能力在 exp24-A 或 exp26-A 就已下降 → 回放提前到对齐阶段（真实图文回放的单变量实验）；只在 exp26-B 下降 → 在决策阶段加真实任务回放，不同时改学习率、解冻层数、损失。
- **磁力**：如果"规则也没用"，先做最小的纯文本任务诊断，不扩充图像数据。

**能说 / 不能说**：exp28 的成功是定位问题、选出下一项干预，而不是涨分。各原因可能并存；证据不能区分时就写不能区分。fields 有 72 题、force_rule 12 题、control30 有 90 题，都是小样本的筛查规则，不是统计检验。
