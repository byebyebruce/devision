- **规则**：

## 两种条件（各 24 个比较请求、72 个字段读出）

| 条件 | 框 | 决策 |
|---|---|---|
| auto | 选择器（产品路径 `Reading.decide`，保存 diagnostics） | 产品路径 |
| oracle | 固定的 oracle 框（`read_with(boxes=…)`，其余步骤与 `Reading.read` 相同） | state 由本次读数构成（与 `Reading.decide` 相同），普通 decide(image=None) |

- **auto 先复现**：
  - 与 EXP59 P 相比，72 个读取（模板、框、解码串、有效性、值）、24 个 table / state、预测都相同，概率差 ≤ 1e-5；
  - 本脚本镜像的读取（`read_with`，框来自选择器）必须与产品路径的读取相同。这一项会多做 72 个字段读出（只用于核对镜像代码，不发决策请求）。
  - 任一不符就停止，oracle 不运行，报告给 invalid / incomplete。
- **金标**：只用于评分，不进任何输入。
- **解释边界**：oracle 下的变化是「所选区域 + 其相对几何」的共同效应，不归因于单一坐标或像素。

## 报告与预写方向

- **内容**：
  - 质量 / 速度 / 距离的整串准确率（auto 与 oracle 各自）、逐字段转移；
  - 速度 oracle − auto 的差值，按 12 张温度图重抽样给区间；
  - 温度四字段全对、磁力两字段全对的图片数；
  - 比较题在两种条件下的转移和配对差；
  - 两种条件的速度框下沿范围。
- **方向**（三条都不授予候选资格）：
  - 速度 oracle ≥ 18 / 24，且改善的下界 > 0：先补选择器监督（版式覆盖取自训练来源，不用这 24 张图）；
  - 速度 oracle ≤ 12 / 24：先准备区域读取的跨版式监督，不只训选择器；
  - 介于两者之间：只记为部分救回，不由此进入长训练。
- 质量 / 距离和比较结果完整报告，不拿来抵消速度这个主问题。这些开发图的框和数值都不进训练，也不把固定的 y 偏移写进产品。

## 运行（`bash scripts/exp60/run.sh`，等许可）

- 顺序：start（不加载模型）→ run（MPS，在 watch 下）→ report。
- 硬上限 10 分钟，最后 120 秒报告；`runs/exp60.started` 只写一次，永不删除；不续跑，不重试，失败就 finalize。
- 预计：EXP59 实测 24 秒（24 个读取请求 + 36 个文字请求）；本轮是 48 个比较请求加 144 个字段读出（另有 72 个镜像核对读出），约 1 分钟。
