# exp24 方案：先做读字对齐，再复测 exp22——读出能不能打通（代码与测试已写，待评审，未运行模型）

日期：2026-10-16。负责人："可以"（exp23 之后的推荐）。不算一轮，不产出可采用的模型。

## 要回答的问题

- exp21、exp22：r15 学不会从图里选出印刷的数字。exp22 只训 16 px 读数题，训练题都没拟合，nll 停在 ln 3 附近。
- exp23：同样的数字在 r15 冻结特征的三层里，用小探针都读得出（16 px：SigLIP 1.000、投影后 0.993、ModernBERT 视觉位置 0.950）。

推断：瓶颈更可能在读出这一步，也就是从视觉位置把数字对应到候选项文字上。

这里问：**先用一个稠密的信号——补全图里印的文字（遮住的数字和标签要从视觉 token 里读出来）——训练 r15，再跑与 exp22 完全相同的拟合测试，这次能不能拟合、能不能推广？**

## 设计

### 阶段 A：读字对齐（`configs/exp24-align.yaml`）

- 用项目已有的对齐阶段 `src/devision/train/align.py`：输入 "[CLS] <视觉 token> <遮住一半 token 的说明文字> [SEP]"，经 ModernBERT-large 的 MLM 头算被遮 token 的交叉熵。
- **起点** r15。投影层用 2e-5 的低学习率（r15 的 lr_new，避免冲掉 r15 的视觉 token），ModernBERT 加 rank 16 的 LoRA，学习率 1e-4（训完合并进 checkpoint）。视觉塔冻结。2 遍，batch 16，warmup 100，mask 比例 0.5，seed 0，每 500 步评一次。
- **数据**（`scripts/data/exp24_text.py`，`data/exp24/MANIFEST.json`）：
  - 训练 20,000 张、验证 1,000 张，按像素哈希去重，两组之间也不重复。
  - 每张图在浅色底上从上到下印 1–4 行字，每行一项：数字（1–4 位，从 1,000 起带千分位逗号）、数字加单位、标签（"Sample A"、"Pair 2" 等）或量名 / 颜色词。
  - 数字墨迹高 6 / 8 / 11 / 16 / 20 px（沿用 exp21 的 `font_for`，按像素实测）。
  - 说明文字就是图里的字，按从上到下的顺序用 ". " 连接。内容是随机的，被遮住的数字没法从周围的文字猜出来。
  - 不画面板、不用 exp21 / 22 的问句和候选，所以阶段 B 测的是迁移。
- **门槛**（`scripts/exp24/gate.py`，运行前写下）：阶段 A 结束时，在 1,000 张留出图上，"配对的图"比"换一张图"的补词准确率高 ≥ 0.30（`align.py` 自带的 `val/mlm_acc_gap`）。没过就停，不跑阶段 B（退出码 10）。

### 阶段 B：exp22 的拟合测试（`configs/exp24-fit.yaml`）

- 与 `configs/exp22-fit.yaml` 完全相同（已 diff，只有 `name` 和 `init` 不同）。起点换成阶段 A 的 checkpoint。数据（exp21 的 2,667 个训练族、16 px、两个数值视图，16,002 题）、学习率、seed、监测（fit / dev16 / dev / 擦除 / 文字对照）、第 2,000 步停止都不变。
- exp22（`runs/exp22-fit`）就是对照：同数据、同批序、同设置，只差起点。

## 判定（运行前写下，结果出来后不改）

- **阶段 A**：门槛见上。只报告第 0 步和最后一步的真图 / 换图补词准确率。
- **阶段 B**：用 exp22 的读数规则和标签，不改（`scripts/exp22/report.py`）。fit、dev16 的 16 px 读数：通过 = 点 ≥ 0.80 且下界 ≥ 0.75；未过 = 点 < 0.60 且上界 < 0.65；擦除对照越线则作废。标签为拟合且推广 / 拟合但不推广 / 没拟合 / 不确定。
- **对 exp22 的配对变化**（`scripts/exp24/report.py`）：第 2,000 步的 fit 和 dev16 读数，exp24 − exp22，同一批题，按族重采样。

| 阶段 B 结果 | 可以说 | 不能推出 |
|---|---|---|
| 拟合且推广，且 dev16 对 exp22 的下界 > 0 | 先做读字对齐后，exp22 的读数任务学得会，而且能推广到未见族 | 小字号也行；ScienceQA 会提高；旧能力不受影响 |
| 拟合但不推广 | 训练切片过线，未见族没过线 | 读字对齐无效 |
| 没拟合 | 加了这一步读字对齐，exp22 的任务仍学不会 | 读出不是瓶颈（也可能是对齐预算或方式不够） |
| 其他 | 不确定，交负责人 | — |

- 阶段 B 成功也只说明这套"读字对齐 + 集中训练"的组合可学。下一步（把读字数据并进正式一轮、补 ScienceQA 的 temp / force、保护旧能力）另写方案，不自动启动。
- 本实验不测旧能力：LoRA 合并进 ModernBERT、投影层也动了，旧能力可能变化。正式方案里必须量。

## 已知限制

- 单种子、一组学习率。阶段 A 2 遍、约 2,500 步；阶段 B 2,000 步。
- 补词的说明文字是随机内容，但标签和量名来自固定的小词表，换图后的成绩会因此高于 0；门槛用"配对 − 换图"的差，不用绝对值。
- 只用 Arial。
