## 题（`scripts/exp31/build.py` → `data/exp31/text_force.jsonl`，sha256 `43ce4224…`；第 2 版，按评审 EXP31-R1-01–03 修改）

空白图，数值写在文字里。数值是新随机生成的，单位有 in / cm / mm，整数和小数都有。代码没有读取或复制任何 ScienceQA 图和转录案例（常见数字本身可能重合）。

| 层 | 问法 | 题数 |
|---|---|---|
| a | 只给两个数，不提磁铁和 Pair："Compare the two numbers: X and Y." 选 X 小于 / 大于 / 等于 Y | 120 |
| b | 哪一对磁铁更近（Pair 1 / Pair 2 / neither） | 120 |
| c | 加规则"越近磁力越强"，问原 ScienceQA 题：强说法（greater / stronger）和弱说法（smaller / weaker）各一次 | 240 |
| d | 距离相同，加规则"越大磁力越强"，大小不同或相同，强 / 弱说法各一次 | 120 |

- **族 = 一个不重复的数值案例**（EXP31-R1-03）：a–c 的族是（单位，无序的一对距离），d 的族是（单位，距离，大小是否不同），都无放回抽取，每个案例只出现一次。共 90 族：距离不等 45、距离相等 15、大小不同 22、大小相同 8。重采样按族进行，同一案例的两种顺序、两种说法一起抽。
- **相等**（EXP31-R1-02）：正确答案是"相等 / 相同"的题，a、b 各 30 / 120，c 60 / 240，d 32 / 120。
- **两种顺序只换数值**（EXP31-R1-01）：每个族把 Pair 1、Pair 2（a 层是 X、Y）的数值对调再问一遍。两次的措辞、选项排列都相同，只换数值。所以非相等题的正确答案随之翻转，相等题不变，这一点由测试核对。
- 选项排列按族固定（固定种子），正确答案落在三个位置的次数是 211 / 193 / 196。
- 第 1 版数据（sha256 `03634d80…`）保留在 `data/exp31.v1-observed-20261017/`。

## 读出（`scripts/exp31/report.py`，只报告，用来定位）

模型：v03 和 exp26B（exp27 导出）。每层报告：
- 准确率，按族重采样给出 95% 区间；另分非相等题、相等题；
- c、d 的强说法、弱说法分别的准确率，以及同一顺序下两种说法都对的比例；
- 族内全对的比例；
- 正确答案和预测各指向 Pair 1 / Pair 2 / 相等的比例；
- 预测落在各个显示位置的比例。

解读方式：
- a 低 → 比不了数字大小（a 不涉及 Pair，与"指认是哪一对"分开）；
- a 高、b 低 → 能比数字，但对不上 Pair；
- a、b 高而 c 低 → 卡在"更近 → 更强"或强 / 弱说法；
- c 强说法对、弱说法错 → 卡在"弱 / 小"的语义翻转；
- 相等题低、预测几乎不指向"相等" → 回避相等，而不是会判断；
- d 单独看大小规则。

不以这批小样本涨分宣称学会了物理推理。
