# exp31 方案：磁力题卡在哪一层——最小纯文字诊断（只评测，代码与测试已写，待评审，未运行模型）

日期：2026-10-17。依据：评审 EXP28-RESULT-02 第 3 项。exp28 里磁力题即使把数值转成文字也只有 3 / 12，再补一句通用规则也只有 4 / 12。这里把题拆成几层逐级问，看卡在"比数字""找更近的一对"还是"强 / 弱的说法"。

## 题（`scripts/exp31/build.py` → `data/exp31/text_force.jsonl`，sha256 `03634d80…`）

空白图，数值写在文字里（提示 + "Pair 1: the magnets are X apart. Pair 2: …"）。数值是新随机生成的，单位有 in / cm / mm，整数和小数都有。没有使用任何 ScienceQA 图、数值或那 12 道转录题。

| 层 | 问法 | 题数 |
|---|---|---|
| a | 哪个距离更小（the distance in Pair 1 / Pair 2 / equal） | 120 |
| b | 哪一对磁铁更近（Pair 1 / Pair 2 / neither） | 120 |
| c | 加规则"越近磁力越强"，问原 ScienceQA 题：强说法（greater / stronger）和弱说法（smaller / weaker）各一次 | 240 |
| d | 距离相同、只是大小不同，加规则"越大磁力越强"，强 / 弱说法各一次 | 120 |

- a–c 共 60 个距离族，d 共 30 个大小族；每个族都把 Pair 1 和 Pair 2 对调后再问一遍。
- 每题的选项顺序打乱（固定种子），正确答案落在三个位置的次数是 180 / 208 / 212。

## 读出（`scripts/exp31/report.py`，只报告，用来定位）

模型：v03 和 exp26B（exp27 导出）。每层报告：
- 准确率，按数值族重采样给出 95% 区间；
- 族内全对的比例（a、b：两种顺序都对；c、d：两种顺序 × 两种说法都对）；
- 同一顺序下强、弱两种说法都答对的比例；
- 选"相等 / 相同"的比例；
- 预测落在各个显示位置的比例。

解读方式：
- a 低 → 比不了数字大小；
- a、b 高而 c 低 → 卡在"更近 → 更强"或强 / 弱说法；
- c 的强说法对、弱说法错 → 卡在"弱 / 小"的语义翻转；
- d 单独看大小规则。

不以这批小样本涨分宣称学会了物理推理。
